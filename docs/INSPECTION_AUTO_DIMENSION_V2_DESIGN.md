# INSPECTION_AUTO_DIMENSION_V2 开发说明

2026-11-01 / MAIN。用户要求将手动调SPAN的双轴标定简化为区域放尺、一键获得比例，
并将底部尺寸表改为工件对应位置的工程尺寸标注。准确基线7cffe56（PR #18），
其依赖#17→#13→#12尚未合并；本任务分支codex/main/inspection-auto-dimension-v2，禁止自动合并。

用户已确认45cm丁字尺有1mm刻度，可水平放置。使用黑色1mm刻线、浅色哑光背景；
取三条512像素水平扫描线，位于x384..895，y304/306/308。标定框显示在相同视频坐标。
ORIGIN且尺寸/CAL启用时，K4短按请求下一完整帧采集；不手调像素间距，不需要访问X/Y确认。
长按不产生标定，不修改原BINARY/EDGE阈值语义。先切ORIGIN，避免同时调整原阈值。

## 比例获取与拒绝条件

仅缓存三条灰度线（384×32bit），以同步读存储逐像素分析，不存整帧、不阻塞视频。
帧几何检查保留提前/同步SOF、valid间隙、tlast与行列数量；无效帧拒绝读取并报错。
按三线整体明暗范围中点自适应判黑刻线，要求亮暗跨度至少48码。
忽略裁切的边缘刻线，完整刻线宽1..6像素；至少16条（15个已知1mm间隔），
相邻刻线中心间距2..16像素，最大/最小间距差不超过1像素。缺刻线、不规则线被拒绝。
每线由首尾刻线中心距离及间隔数计算100mm等效像素跨度，四舍五入，允许200..1600。
至少两线跨度相差不超过8px/100mm才成功；取一致线对均值。单线不宣告成功。
新请求先撤销旧标定；取消、复位、失效流不产生CAL OK。退出CAL本身不确认比例。
状态码0需标定、1等下一完整帧、2分析、3成功、4无对比、5不规则/不一致、6视频几何错误、7取消。

这是已知1mm周期标尺的读数器，不是数字OCR或任意尺型识别。厘米刻度、等间距纹理、
漏掉全部短刻线而只剩规律长刻线等可能形成尺度歧义，不能由算法证明物理单位。
操作者必须让每条1mm短刻线都清楚穿过至少两条扫描线，并用独立已知尺寸复核。
不能用“识别通过”替代计量验收。存在反光、透明尺底纹、失焦、斜放等拒绝或误读风险。

水平尺只直接约束横向比例。本版X/Y共享比例，适用固定俯视、近似等比例投影及同一平面，
不声称独立Y轴标定、透视/畸变修正或高精度。必须分别用已知水平和垂直长度检验；
若比例不等或误差随位置变化，该公共比例方案不得通过验收，应回退双轴/二维标靶方案。

## 对应位置的标注

保留现有单件轮廓、轴对齐外包宽高、固定中心孔槽截线，不扩展为自动CAD或三视图推断。
不测隐藏边、厚度、多孔中心、圆弧拟合。外包W放在工件上边，H放右边，配尺寸线、
引出线、箭头和实际数值/单位；X/Y孔槽截线使用统计得到的真实截线端点，不猜中心对称。
标注使用现有等宽16px字形、透明背景。测量界面不再在底部显示W/H/GAP参数表。
CAL在框旁给出短提示和结果；运行无有效工件时给出NO VALID OBJECT，不留下旧尺寸线。
结果仍对应上一个完整采集帧（继承LAST口径），运动时不是同帧绑定，标注可能暂时滞后；
这版面向静止固定工件，不能宣传动态精密测量。数字小数位仍不代表实际精度。

颜色比对原理、五模式算法、K3/K4正常功能、Sensor/AWB/BLC/曝光增益、MIPI/DDR/HDMI、
PLL/引脚/SDC及队友工程冻结；只更换尺寸应用标定/绘图，视频公共延迟不增加。
保留旧manual模块及默认关闭的新参数，历史candidate可直接烧录回退。
先独立读尺和绘图测试、旧版回归，再真实路径720p五模式/打包校验和完整TD流程。
当前基线Slice94.47%、ERAM85、Setup+0.152ns；新方案必须用实际布局结果验收，失败不bitgen。
原第四物理开关无效问题仍未定位，不擅自猜引脚改线；尺寸开关按上一轮前三路实板行为操作。
原FIFO B/S和Gray指针覆盖风险仍须长期观测，本任务不以标定或STA掩盖视频可靠性问题。
