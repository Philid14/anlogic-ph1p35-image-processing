## 原传感器控制隔离

Top解除ae_set实例，传感器配置入口I_ae_req固定0，I_ae固定1990，I_ag为不使用的固定值；旧ae_set/写表/增益表源码保留。uicfgcs500_720p初始化状态机仍执行同一张冻结初始化表；完成后O_ae_cfg_done保持1且请求为0，不能进入曝光/增益重写。测试覆盖反复按键后无Sensor更新请求，并核对初始化表和ISP冻结文件SHA。未增加AE。

## 控制时钟与提交边界

两个按键在既有24MHz域经两级同步、20ms稳定消抖、单事件检测。长按计时从消抖按下开始，单次触发。源域保存请求 `{mode, threshold[7:0]}`；独立CDC邮箱用请求/确认toggle同步，发送数据从launch保持至ack，目的域在同步请求到达后整体捕获。忙期间新请求保留最新状态并在ack后再次发送；不把多位配置逐位同步。

在AWB实际输出的提前tuser处锁存目的域收到的完整请求；请求在边界同拍或稍后到达则留到下一帧。考虑同拍SOF/首valid，第一拍直接使用本次提交值。模式、阈值随每个输入拍进入流水，旧帧尚在流水内的像素继续使用旧配置；一帧内保持同一配置。

## RGB/Sobel流水与空间定义

Sobel持续更新行缓存，ORIGIN时也不停。保留灰度、相邻像素对平均、两行缓存、梯度、14bit幅值和、5级总流水及边缘排列；比较阈值为8bit，经零扩展到14bit，阈值同时携带到S4→S5比较位置。不得截断梯度为8bit。

Original RGB及valid/user/last同步寄存5级，与Edge输出拍、流坐标完全一致，再选择输出。保留EDGE_V1的因果空间定义：输出位置(x,y)的Edge核中心在约(x−2,y−1)，640点横向采样且成对复制；Original保持原(x,y)像素，不通过额外行移位破坏原图。拍数相同不等于图像特征无空间偏移，仿真分别核对原像素及已确认的因果Sobel空间模型。

## OSD与DDR帧对应

正式DDR输入camera→DDR异步FIFO，四个DDR帧地址轮转；输出读指针由写入帧通知更新并在HDMI帧通知派生的DDR域脉冲处选用。当前没有随帧携带的模式/阈值元数据接口，不能仅同步“当前模式”到HDMI就证明它对应正显示的缓存帧。

因此新增OSD在算法选择后、96/128打包前叠加，状态直接成为该帧的像素。即使DDR排队、丢帧或重复显示，文字仍跟随其对应图像；不另建控制→HDMI状态跨域。既有DDR/FIFO/HDMI接线配置保持，DDR后的安路Logo/CNT混合器及字库源文件保持原样。

复用正式osd_char_lib的16×16 ASCII字模，2倍显示为32×32字格，右上角X800/Y16；第二行Y56。14字符：`MODE: ORIGIN  ` / `MODE: EDGE    `、`THRESHOLD: 080`。矩形448×72，不与Logo(0..159,0..159)或CNT(375..574,120..143)重叠。三位十进制独立正确转换，覆盖010/080/100/250。独立两级文字流水，字符选择与字模/像素混合分开；data/valid/提前user/last统一延迟2拍。总AWB后7拍，再打包1拍及行尾补偿1拍；提前SOF与有效像素间距保持。
