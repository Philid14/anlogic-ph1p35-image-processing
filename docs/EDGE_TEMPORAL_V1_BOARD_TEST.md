# EDGE_TEMPORAL_V1 最小实板对照

本轮候选为真实RGB正式处理路径，无ROI绿框、无101页编码画面。精确bit/SHA/源码/tag以同版本BUILD_INFO和最终交付为准；未签发candidate前不要使用R0等中间bit。

## 先验证视频可靠性

1. 固定相机、黑白纸边/眼镜和灯光。沿用原供电、线材、Sensor/ISP参数；PROGRAM_SRAM烧录正式EDGE_TEMPORAL_V1 candidate，确认文件SHA。
2. K3检查ORIGIN彩色与EDGE切换；K4短减10/长加10，默认TH80，原MODE/THRESHOLD、安路Logo、CNT应正常。状态区多一行`B:hhhh S:hhhh`，均为十六进制饱和值。
3. 重置后约5/30/120秒各记录一次B/S即可，不需要再录编码页。B是前600采集帧中发生写/full事件的帧数，S是之后异常帧数；不是丢失beat总数，不是当前帧身份。计数在下一SOF公布并随图像显示，允许少量显示延迟。
4. **S若持续增加，或非零且来源尚未确认，暂不通过正式稳定性验收。** 保留照片、发生阶段、是否伴花屏/失锁，优先定位FIFO/DDR。B非零而S长期0只支持本观察窗口未记录稳态事件；不能断言历史溢出纯属启动或CDC风险排除。FFFF为饱和异常，不能当“没再变化所以正常”。

## 再做旧/新画质A/B

旧版：artifacts/bitstreams/EDGE_QUALITY_V1/camera_to_dsi_display.bit，SHA `629ACAA828EF8151DED0261779ED8B91F0FA618EED66DD46C72D6E799ADCC9D5`。

新版：artifacts/bitstreams/EDGE_TEMPORAL_V1/camera_to_dsi_display.bit，SHA见BUILD_INFO。

每版使用相同机位、固定目标、灯光、显示器和手机设置；锁手机曝光/白平衡/对焦，取景包含完整显示区，避开反光。不要手持纸边作为纯静态实验。重新编程后先等AWB收敛和可靠性检查窗口，不把启动瞬态计入画质比较。

每版按同样顺序做：

| 场景 | 操作 | 重点 |
|---|---|---|
| 静止 | 纸边/眼镜固定，TH40/60/80各录10秒 | 白线出现消失、局部左右跳变、轮廓缺口、线宽与背景杂边 |
| 慢移 | 固定TH60，缓慢平移纸边 | 是否短暂双线/增厚；新方案允许短保持但不能明显拖尾 |
| 快移/消失 | 同TH快速移出，再移入，重复3次 | 是否立即检出、背景是否残留白线，出现/消失响应 |
| 光照变化 | 目标不动，切换现有灯光后恢复 | 连续显示、异常S计数、恢复情况；不改Sensor或阈值掩盖问题 |

切阈值后等待约1秒再比较，阈值改变会主动停用旧历史。忽略Logo/CNT和全部状态OSD区域；它们不是静态边缘。先描述定性差异，手机显示录像不是原生采集RGB或精确FPGA帧率测量；如量化应保持两版录像采样条件一致并说明显示刷新/滚动快门限制。

## 接受与回退

- 同TH下，静态闪烁/峰位变化可见减少，真实轮廓保留，慢移增厚与消失响应可接受，才支持继续采用；不能只看白点数量或某一静态截图。
- 若仅变粗/杂边增多而无明显稳定收益，回滚QUALITY；不自动调参、提高阈值或叠加其他滤波。
- 最后至少30分钟连续显示及明暗切换，无花屏/缓存异常，S不增加；该结果由用户反馈，不能由本机仿真代替。
- 反馈：版本/bit SHA、5/30/120秒B/S、固定/移动目标、各TH旧新差异及原视频路径。当前只交付本candidate，不自动合并PR或进入下一版。
