## 怎么理解“已有”

- **A：本候选版本绑定的正式板测**：目前未找到。需要实际加载文件SHA、操作/条件、原始记录和验收结论。
- **B：实物或历史观察**：用户确认、拍屏文字转录、旧阶段PARTIAL反馈。说明现象出现过，不能替代新候选验收或精度结论。
- **C：数字/实现证据**：独立模型、原生RTL、实际整机P&R及bit归档。不是物理成功或长稳数据。
- **缺少记录**不等于功能失败；**已有失败现象**也不能写成“未测”。建议实验次数/时长不是官方硬门槛。
