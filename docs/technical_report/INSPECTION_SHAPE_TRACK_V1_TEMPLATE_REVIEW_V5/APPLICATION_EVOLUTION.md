## 变化过程：现象/约束→选择→收益与代价→待验证

按工程版本顺序组织。表中“意义/取舍”是对已有实现的工程解释；只有原始记录明确出现的反馈才作为历史触发依据，不把事后分析冒充当时已做的选型实验。

| 阶段 | 已有现象或需求依据 | 实际变化 | 工程意义、代价与验证边界 |
| --- | --- | --- | --- |
| 视频与画质底座 | 历史用户反馈偏色、灰雾、亮度不足，OSD/Logo仍可见 | 分别推进AWB样本、BLC和固定增益对照，再冻结相关参数 | 单变量推进便于归因；有主观改善及增益分档变亮反馈，尚非标准色卡、噪声或长期稳定量测 |
| 从通用处理到固定台应用 | 用户确认最终以固定平台颜色比对和薄工件尺寸为主体；历史日志记录在已能上板的STYLE基线上开展颜色应用 | 增加固定双ROI RGB均值/差值及界面 | 场景更具体、读数更容易解释；仍需样品覆盖ROI，不能推出标准色度准确度 |
| V1手动尺寸→V2自动读尺 | 归档显示V1需100mm手动双轴操作；V1反馈中默认SPAN0256和CAL:OK并未证明真实对齐 | V2改用1mm刻线自动定标与实际端点工程标注 | 减少手工调span的操作；不代表V1有已验证精度，也不代表V2物理自动标定已成功 |
| V2→V3可用性 | V2阶段透明尺CAL FAIL，128×128色框混入多个色块/隔线 | 色框缩为32×32，改进多行读尺并增加SW/R诊断 | 降低样品/背景混入、使错误可观察；仍需真实尺和场景验证，不能认定失败根因已唯一定位 |
| V3→V4区域搜索/颜色解释 | V3反馈小框可见，同一黄纸两侧RGB仍不同，并提出扩大CAL | 大框768×288、27带搜索；保留原差值，增加CHR/DV及LIGHT/CHECK | 增大放尺范围，区分原始码值接近与可能亮度因素；LIGHT不自动等于同色，左右差异原因未被受控实验隔离 |
| V4→VISION资源与动态扩展 | 高Slice占用；记录保留运动历史推断为分布式RAM时超容量的失败尝试 | 无损Logo字典、显式ERAM与负载复位优化，再加入红色观察和块均值帧差 | 在资源交换中实现扩展，存在FF/ERAM增加等代价；独立综合不是整机P&R，动态/长稳仍待板测 |
| VISION→RULER_CM_CAL_V1 | 近期拍屏为1MM/R5/CAL FAIL，实际bit SHA未核验；记录明确用户接受大致比例，要求厘米刻线像素间距平均 | 至少5条厘米长线，行内4个以上间隔平均、同帧相邻双行一致，完整27带选较大稳定周期 | 放宽对密集毫米线的输入要求，定位为粗比例尺；不是OCR，仍可能半厘米/纹理倍数误认。新R3、独立X/Y真值、成功率和耗时尚无实物记录 |
| RULER_CM→INSPECTION_SHAPE_TRACK_V1 | 主控归档记录反光金属漏分割、圆瓶盖只有W/H、TRACK整块绿覆盖/缺框；多个全功能尝试超资源 | 新增空台面网格绝对差，手选D/R，复用LAST边界外框；配置改原生ERAM延迟，恢复原字库 | 公共流水仍31拍；Slice+377/ERAM+3，余113/3。背景需平滑固定，D/R非自动识圆，LAST滞后/源停旧DDR画面仍在；物理闭环待E04→E11→E05/E12/E06 |

## 还没有依据、不能补写成“已经证明”的原因

- 没有找到充分的YCbCr与HSV同条件准确率/资源对照；目前只确认实际方法不同，不给这一变化补造优越性结论。
- 同黄纸左右RGB差异不能仅凭照片认定全由照明引起；相机响应、反光、背景与摆放等贡献需受控对照。
- R5证明当前间距判据未通过，不证明单一对焦/倾斜/光照原因；真实烧录版本未核验时也不能归到某tag。
- 厘米方案的新R3/CAL:OK不能单独证明单位正确或双轴准确；需独立工件排除2倍/5倍误读，分别测X/Y及位置敏感性。
- 资源优化已归档，严格同帧颜色历史框、蓝色、内部同帧延迟和完整板测仍是缺口，不用“持续迭代”措辞掩盖。
