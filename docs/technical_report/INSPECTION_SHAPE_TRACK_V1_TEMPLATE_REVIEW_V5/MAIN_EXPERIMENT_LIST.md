### E01 启动 基础画面与七模式

- 输入：SW诊断值0000；启动约1分钟；移动明显物体；K3完整循环EDGE→ORIGIN→GRAY→BINARY→STYLE→TRACK→MOTION→EDGE，建议重复3轮。物体动作与屏幕同场录像。
- 数据：下载/出图是否成功、首次出图时间、各模式名称和Logo是否可见；模式切换时间点、黑屏/花屏/错行/冻结/回跳次数及持续时间。
- 独立预期：每次稳定按键切换一次，模式顺序正确；原图动作连续；不同模式保留正确几何关系；Logo不被应用遮挡。EDGE/BINARY的K4短按−10、长按+10，默认80/130；TRACK/MOTION的固定检测阈值不随K4改变。
- 失败条件：多跳/不切、阈值改变了错误模式、视频持续冻结、Logo消失、处理区与原图错位。出现时先停止画质/精度结论，保留输入操作和计数。
- 文档用途：基础要求、进阶切换，以及3.2.3实拍界面。仅现场“看起来顺畅”不能支持实测60fps。
- 当前：旧版基础出图/五模式/Logo有确认；本候选七模式、阈值和实时性未验收。

### E02 长期稳定与光照变化

- 输入：相机固定、样品静置；先稳定运行，再分别做移动物体、K3切换和明暗突变；先取得一段30分钟连续记录，有条件再延长。30分钟是内部建议，不是官方最低时间。
- 数据：启动5秒、30秒、120秒及长稳末尾的FRAME、ERR、B/S、模式和录像时间；每次光照变化时间点；花屏/冻结/回跳/错位/异常重启次数，恢复方式和耗时。记录连续有效观察时长，暂停和重启另列。
- 已核源码的计数口径：B/S为HEX、饱和FFFF，计数单位是“含write-valid且FIFO-full事件的帧”。B为前600采集帧，S为之后；不是亮度/饱和度或像素数。启动B非零不等于稳态持续丢帧，**S继续增长优先定位吞吐/缓存**。ERR是视频协议sticky错误，不是置信度。请补复位/清零行为的实际操作记录；不可读的内部欠读等仍填未测，不能由画面正常填0。
- 独立预期：固定输入下视频仍连续；变光不应让链路永久停止；变化后状态恢复并继续产生新的采集FRAME。手机录像丢帧与FPGA丢帧须区分。
- 失败条件：稳态错误持续增加、源FRAME长期不动而屏幕仍重复、恢复必须反复下载、出现不可解释错行或持久花屏。
- 文档用途：直接补赛题长期/强光变化稳定性；只有版本绑定记录才能写“在某条件下连续运行N分钟观察到X次异常”，不能写任意条件零故障。
- 当前：无完整版本绑定的长稳/强光变化记录；历史单张计数不能证明全程。

## 应用效果与可量化指标（先E04→E11→E05，再E12；颜色另组）

### E03 双区颜色比对

- 条件：样品覆盖32×32采样区，位置为参考x304…335/y304…335、测试x944…975/y304…335；相机/照明先固定。使用有身份标签的样品，不靠屏幕颜色作为真值。
- 分组：①同材质同色左右交换；②明显异色；③同样品仅改变一侧照明/遮光；④暗、近饱和、反光或背景混入。建议每组至少10次独立放置，组间条件写清。
- 数据：样品ID/材质/预期类别、每次两区RGB均值、ABS/L1/MAX、CHR/DV、MATCH/LIGHT/DIFF/CHECK/WAIT，原图与状态照片；成功和失败全部保留。
- 独立预期：完整、可靠的两区数据才判别；原始MAX≤12是码值接近；原始不匹配但CHR≤6时可能LIGHT；暗/饱和应优先CHECK。LIGHT只能说明比例接近，不能自动当成“颜色相同”。
- 分析：每组状态分布、误MATCH、误DIFF、CHECK/WAIT次数与原因；报告样本数和左右交换敏感性。将不可靠样本单列，不能删除后只报成功率。
- 失败条件：样品交换造成系统性偏差、错误异色被MATCH、未完整区域仍有有效判别、状态不随新观测更新。须区分算法边界与视频异常。
- 文档用途：支撑“同条件下的RGB一致性筛查”和亮度因素提示；不能从这些数据推导CIE ΔE、色度计精度或照度。
- 当前：旧版面板、RGB及同黄纸左右差异已有反馈；本版判别分组与误判统计未测。

### E04 厘米长刻线粗标定

- 已有：旧透明尺CAL FAIL、近期1MM/R5/CAL FAIL；实际旧bit未独立核验。新厘米候选仅数字/构建通过，没有R3实物成功记录。
- 输入：已知公制尺、黑色厘米**长线至少5条**，水平、清晰、浅色干净背景；尺/工件同平面，相机正俯视。相邻厘米距12…120px为源码接受范围，不是由屏幕自动识别单位。
- 操作：ORIGIN+DIM+CAL，确认AREA **1CM RULER LONG TICKS**，短按一次K4，保持静止直至CAL:OK。约54个采集帧加分析等待；不要连续重按。屏幕逻辑SW通常0101→成功后0100（关CAL留DIM），实体路序/极性现场核对。
- 分组：上/中/下摆放、不同照明、轻微倾斜；反光/模糊/只有短线/规律纹理作边界，保留实际刻线照片。不要把厘米输入仍写成旧密集1mm规则。
- 数据：尺型号和单位、可见长线数、相机高度/倾斜/位置、请求时刻、全部R状态、请求/成功次数、R3耗时；能读则存S100，不能读则用独立尺寸检验。拍屏必须包含原图和状态。
- 独立预期：12行缓存扫描27带；行内至少4个厘米间隔平均、同帧相邻双行一致，完成整框搜索再选较大稳定候选；S100=10×厘米像素距（120…1200px/100mm），不是厘米像素距本身。例如d34px→S100340，P170px→50mm（算例，不是实测）。
- R3/CAL:OK只表示周期一致，仍可能出现半厘米或纹理倍数误认；必须接E05。新请求清旧尺度，R6不接受已缓存候选，取消不确认；R5是间距未通过，不能据此判链路帧错误或唯一光学根因。
- 失败条件：R3后独立真值约差2倍/5倍、错误纹理通过、失败/取消仍沿用旧有效尺度、异常帧提交候选、旧1MM界面被当新版测量。
- 文档用途：证明粗比例尺的真实可用条件、成功率和耗时；不写精密标定或0.1mm准确度。
- 当前：旧失败反馈已有；本候选厘米标定成功和统计未测。

- 数据：标定ID、背景学习ID/BG/AUTO12或CUT、位置/角度、明暗前景选择、读数单位与W/H/GX/GY、有效/无效状态、实际外框/端点照片、重复编号。

- 文档用途：将“0.1mm显示”变成有量具、样本和条件的实测误差描述；没有这些数据不得宣称0.1mm精度、任意形状内外径或工业计量。

## P1 进阶项和恢复过程

- 输入：SW0000，K3进TRACK；单红卡慢移左/中/右与上/下、快移、静置、移出、重现；再加入第二红物体、红背景、小红块和反光。录像同时拍物理动作和HDMI，避免只拍静态屏幕。

- 独立预期：显示2像素绿色外框，框内仍是原红色，不再整块绿填充。框、中心、N、FRAME来自同一LAST完整观测，在SOF成组更新；X右移增、Y下移增，N是像素数。3次可靠正观测进入TRACK，重复HDMI刷新不能代替新采集观测。
- 时序边界：框是上一完整采集结果，快移可见帧级滞后，不能按严格同显示帧要求报告成功。移出/无效完成结果撤销框；SOURCE停止时DDR可能重复旧图连同旧框，应出现STALE提示，不要求不存在的“断流自动抹旧DDR框”。

## P2 有仪器后补齐实时性

### E10 刷新率 新帧率与延迟

- 刷新：记录显示器信息页、抓取设备或测量仪器的刷新读数；75.002MHz/(1650×750)约60.61Hz仅是STA约束与RTL总时序计算。显示器标称60Hz不等于实测独立新帧60fps。
- 新帧率：固定真实时间窗，记录采集FRAME增量，说明计数是否回绕/跳变、采样是否漏读；HDMI CNT定义由MAIN说明。源/显示可重复或跳帧，分别报告。
- 光学延迟：高速录像同时拍到物理事件与屏幕对应变化，写录像fps、起止判据、至少若干次原始帧索引及时间量化误差；包含曝光和显示器，不直接写成内部处理延迟。
- 内部同帧延迟：仅在真实身份、采集首有效像素、HDMI同帧首有效像素、统一时基与CDC口径均可观测时测量。当前该整机路径未完成，不用31拍、两次帧号相减或SOURCE STALE（源码/旧资料也称VIDEO STALE）门槛替代。
- 文档用途：将配置实时性提升为有口径的量测；本项未测不应抹去已实现的像素流水，但不能宣称进阶延迟可视化完成。
- 当前：STA配置/流水深度已有；刷新、新帧率、延迟均未测，内部同帧计时未完成。

## 新候选专项实验

### E11 空台面背景参照与反光外廓

- 输入：ORIGIN、DIM开、CAL关（通常SW0100），先完成E04尺度。移走尺和工件，保持相机/平台/光照，**空台面短按释放K4**；等BG状态更新，再放薄工件。拍下完整操作，避免误把装有工件的学习当正确基线。
- 分组：平滑空背景；哑光薄片；反光金属；相对背景亮/暗物体；背景纹理、阴影、变光、移动相机和触ROI边界。移动/变光之后先记录旧参照影响，再空台面重新学习。BINARY仍是CUT阈值预览，不能用它替代AUTO12掩码。
- 数据：标定ID、背景学习ID、BG:NEED/WAIT/OK/FAIL、AUTO12/CUT、空台面照相、学习时刻/耗时、各工件W/H及真值、有效/无效、外廓/丢失区域照片；对照组固定其余条件与量具真值。若需旧bit对照，单独run，说明版本与参数差异，不能把多处变化归因唯一算法。
- 独立预期：完整有效帧、正确行尾、1152格学习完成才发布BG:OK。16×16格每格中心行四样本，绝对灰度差≥12可收正负差；无就绪参照回退CUT。复位/进入CAL/重学清参照；帧中请求不会产生半新半旧参考。真实无对比/过曝边缘仍可能失败，不将此现象隐藏。
- 几何门限：连续段≥3像素、每行≥6合格像素、至少3行/64像素、触ROI边界无效。背景只改变分割，不改变尺度。先检查轮廓端点，再解释W/H误差。
- 失败条件：学习不完整却显示成功；空台面持续误检未说明；半幅参照混合；重学/进CAL/复位仍沿用旧参照；条件改变后继续给出可信尺寸且无风险说明。受阴影/纹理影响应归为适用边界或失败，不宣称万能消反光。
- 文档用途：把“反光反馈→参照方法→真实外廓/尺寸→失败边界”连起来。归档70px→140px是真值140px的合成例，绝不能当实板提高100%的证据。
- 当前：背景原生4帧720p/1152格数字测试已有；真实BG学习与反光改善尚无版本绑定记录。

### E12 显式圆片D/R与负例

- 输入：已完成E04和E11，单个完整正俯视圆瓶盖/圆片平放，不触ROI；ORIGIN测量RUN长按K4约1秒，确认K4 HOLD: D/R及D/R标注，再长按回W/H。一次长按不应连续反复切换；短按仍是空台面学习。
- 独立真值：量具测实际外径并注明仪器/分辨率、圆片ID/厚度；R真值用该独立外径除2，与屏幕R=D/2算术一致性分开评价。不能用打印设计尺寸替代成品量测。
- 数据：至少若干尺寸圆片、中心/边缘重放、角度和高度；D/R原值及MM/PX、有效状态、半径线端点、真值/误差、切换次数与长按是否误触发学习。次数按实际时间安排，不规定为官方门槛。
- 独立预期：手选D/R只改变解释和标注；D为水平外框跨度、R=D/2，半径线中心到右边界。未标定应PX、标定后MM。自动形状分类生产SHAPE_ENABLE=0；方片也可被操作者切D/R，因此UI出现D/R不证明自动识圆。
- 负例：斜放圆片、异形/正方形、部分圆弧、双目标、反光孔洞；记录无效或不适用，不声称任意圆弧拟合、真实内径/厚度。GAP仍是固定中心截面，与D/R分开。
- 失败条件：一次长按反复切档、长按误学习；D/R与W/H单位或尺度不一致；半径线端点错误；把手选档写成自动形状分类；不完整圆弧读数被当真实直径。
- 文档用途：补已知圆片实际使用、尺寸误差和人机操作，解释为何选择显式档而非超资源的自动分类。
- 当前：模式/几何/2帧720p绘图数字通过；真实圆片D/R精度、姿态/反光边界未测。

## 如何把数据转成更有说服力的报告

以下仅为回填句式，方括号必须用真实记录替换；不能直接复制成已完成结论。

- 稳定性：在[bit/设备/环境]下连续运行[时长]，执行[切换次数/变光次数]，观察到[花屏/冻结等各类次数]；源FRAME及B/S增量为[记录]，异常通过[方式]在[耗时]恢复。比“长期稳定”更可核查。
- 尺寸：在[相机高度/样品厚度/标定条件]下，对[样品数/摆放次数]分别测X/Y，最大绝对误差[值]、平均绝对误差[值]，位置变化造成[现象]。这说明尺度方案的适用范围，不能仅写0.1mm。
- 颜色：对[组别/样本数]进行独立放置，状态分布为[数量]，左右交换/单侧变光出现[现象]；[失败原因]时给出CHECK或误判。它体现可解释性和边界，比“颜色识别准确”更具体。
- 进阶动态：在[移动/静止/重现/灯变]条件下，TRACK/MOTION分别出现[标记/状态/恢复]，计数单位为[像素/块]。可展示硬件并行观察与可信状态的作用，但不把LAST、GLOBAL或心跳扩写成未实现的能力。
