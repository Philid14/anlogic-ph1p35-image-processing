## 必补的实物资料

1. 正面和45°全景：相机、检测平台、光源、FPGA板卡、显示器同场；另提供接口和供电局部照片。
2. 实际框架尺寸、相机高度、镜头/视场、目标厚度、光源型号/布置、线材长度、显示器与供电信息。
3. 当前候选bit哈希和PROGRAM_SRAM结果；启动约1分钟及七模式完整切换录像；Logo、阈值、FRAME、ERR及B/S可读。

这些资料将“架构示意和用户口头确认”提升为可审查的成品及配置证据。没有它们不能用概念图代替实物图。

## 必补的应用实验

| 实验 | 最少原始记录 | 可以增强的结论 |
| --- | --- | --- |
| 颜色比对 | 同色换左右、异色、单侧变光、暗/饱和/反光；保存两区RGB、MAX/CHR、状态及重复次数 | 判别正确率、典型误判与LIGHT的解释能力 |
| 标尺 | 1mm刻线实物、R状态、成功次数/请求次数、耗时、失败照片 | 自动标定是否真正可用及使用条件 |
| 二维尺寸 | 建议至少3种真值尺寸，中心/边缘分别重复5次，X/Y分开；记录量具分辨率、厚度、标定状态与读数 | 最大绝对误差、平均绝对误差、重复性和适用范围；不能预填精度 |
| TRACK | 红卡移动/静置/移出重现/第二红物体；原图、当前标记、LAST HEX坐标及状态 | 定位跟随、观测更新、合并边界、恢复表现 |
| MOTION | 静置/移动/停止/移出/灯变；CHANGED、STILL/MOTION/GLOBAL | 运动检出、静态误报、全局变化局限 |
| 异常与长稳 | 受控复位、5/30/120秒和至少30分钟末尾计数；异常触发和恢复方式 | 连续输出、恢复能力、系统稳定性；内部未观测的计数仍写未测 |
| 帧率/延迟 | 仪器或高速录像方法、采样率、事件对应及误差；区分刷新/独立新帧/光学延迟 | 把配置目标提升为实测实时性；不以31拍或帧号差替代 |

## 每次回报的统一字段

`日期/操作者；tag/bit SHA；板卡/相机/显示器/线长/供电/光照/高度；模式和SW读数；操作顺序；FRAME/ERR/B/S；现象、次数、持续时间与恢复；录像/照片/数据路径。`

失败同样保存。尚不能读取的内部溢出、欠读、真实新帧率或延迟一律填未测。当前所有实验条目均等待执行，没有设置虚构的PASS或实测阈值。
