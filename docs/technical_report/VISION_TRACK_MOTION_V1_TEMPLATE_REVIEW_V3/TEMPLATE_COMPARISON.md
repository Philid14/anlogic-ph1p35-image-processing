## 有意作出的调整

1. **保留而非另造版式**：恢复模板A4、上下2.54cm/左右3.175cm、宋体/Times New Roman 12pt正文、1.5倍行距，保留官方彩色图形页眉、横线、原页码域与原节属性。上一版自设页眉及2cm/2.2cm边距不沿用。模板彩色图形是官方品牌元素，不是另外添加的标题装饰。
2. **名称槽填入真实名称**：替换“作品名称”及红色匿名提醒，新增一行候选版本/待测状态，采用10.5pt次要文字；标题为18pt，与模板标题字号相同，并使用Word Title样式。没有学校、学生身份或虚构作者。
3. **增加细层级，不增加第六部分**：在2.3.2和3.3之下增加小节，容纳真实模块、取舍和证据；第一部分不再另加1.7/1.8，原方案差异移到2.3.2.7，赛题对应移到3.3.1。
4. **新增图表与公式**：模板没有表格格式，新增浅灰表头/边框的10.5pt表格、14.65cm内图幅和10.5pt图注；正文保持12pt。新增标尺/测量与观察器流程，毫米换算用原生Word公式；无合成实物照和虚构曲线。短表尽量整体分页，标题随正文。
5. **将内部审阅材料移出报告**：不把空白实验附录和PR操作过程拼入五部分正文。主控实验清单、模板对照、证据/检查记录为配套文件，便于补数据后生成提交版。报告保留必要的版本和实验边界。
6. **参考文献补充完整定位**：统一网络/数据/源码条目要素和固定commit地址；这些链接属于私有项目证据，正式材料需同时提供评委可访问的源文件/报告附件或允许的材料入口，不能仅依赖私有GitHub。没有改变仓库可见性。

这些是对用户“参考模板，最好按模板，改动需注明”的具体落实，不是模板本身对字号/页数的额外强制规定。若提交门户还有统一封面、文件大小、页数或匿名细则，应按该额外要求再核对。
