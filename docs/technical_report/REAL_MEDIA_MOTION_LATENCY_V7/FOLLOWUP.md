## 优先完成的六件事

### 1 核清实际运行版本

记录实际下载 bit 的文件名、完整SHA-256、tag、下载时间和操作者；视频记录使用同一 run ID。PowerShell 对实际下载文件执行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '实际下载的bit完整路径'
```

当前交付说明指向 LATENCY_FRAME_FIX_V1，SHA应与 README 的 `d516…2c16` 对应。请主控按批准的 PROGRAM_SRAM 流程核验；只记录实际使用版本，不根据拍摄文件时间或界面外观倒推 bit。原 DEMO 片段保持其历史标签，不改写为真实修复版。

作用：把本稿的源码、全构建、bit与实物连起来，才能把“改进运动已观察”升级为某一指定版本验收，也能避免把不同候选混用。

### 2 拍真实延迟面板

在主控批准的真实修复版本上，冷启动后约5、30、120秒分别拍清完整面板，留一段足以看清数字与状态持续变化的视频。须同时包含 LAT/MIN/MAX/AGE、状态、F/N/E、C/W/D、B/S、Logo和模式；记录这些读数，不能只截LAT。

| 观察 | 怎么解释/怎么汇报 |
|---|---|
| 仍出现 DEMO | 这仍是模拟面板，不能填真实性能；先报告 bit SHA |
| N持续增长，NEW有效 | 才具备报告不同帧有效样本的前提；保留三时点原值 |
| REP | 重复显示本身不应新增独立有效样本；需身份/内部证据或可重复控制来核验，不能靠手机漏拍的两帧推断 |
| N0、BAD或WAIT | 没有有效样本；零不等于零延迟，保留LAT旧值也不等于有效 |
| N0但画面与CNT更新 | 视频活着与计量成功是两件事；拍清 C/W/D 交 MAIN 定位资格拒绝 |
| E或S增长 | 记录起止值和触发动作，不能用“画面看着正常”忽略；C/W/D是诊断，W是实时状态，不保证与C/D原子同次 |

测量口径是解码后RAW首有效拍至同一帧HDMI首真实DE，包含ISP/缓存等待，不含曝光、相机内部或显示器内部。10us为配置量化，75MHz尚未物理校准。若只有面板读数，注明这是内部测量；若要光学端到端延迟，需要独立同场事件/高速录像并记录采样误差，普通手机画面不能自动得出精确毫秒。

作用：直接对应赛题“采集至显示处理延迟测量与可视化”；能补入有效样本量、范围、重复帧与失败原因。现有DEMO的10—30ms或截图28.81ms一律不能代填。

### 3 用独立量具量实际样品

每种至少选一个矩形、圆片、轴对齐T/L薄件，用游标卡尺或明确分辨率的尺独立量真值；记录器具、单位、样品厚度和对应照片。先正确厘米标定，再移尺、空台面学习，确认 CAL:OK、BG:OK 与实际AUTO12。保持光照/相机不变，独立取放10次作为建议最小重复组；这不是官方指定样本数。

矩形记录X/Y；圆片记录外径及D/R界面；T/L逐项对应W/H/S/T/A/B/V，零伸出侧隐藏不是漏项。T横梁水平、薄件同平面、完全在ROI内，旋转或复杂件回退W/H也要保留。无效、CUT回退、裁边等逐次记原因，不能只留下成功截图。

作用：把“显示98.3mm”“0.1mm小数位”变成可核验误差/重复性；独立D真值不能用界面R=D/2互证。可据此写最大/平均绝对误差、摆放范围及适用边界。

### 4 补背景学习和运动的受控对照

背景：固定同一件反光工件、位置、灯光，记录学习前CUT/NEED、移物学习、BG:OK、放回后的AUTO12及轮廓/读数；若仍漏边或出现阴影外框，如实保留。高光使边缘消失不能声称被背景差恢复。

运动：本批已见密集点阵与STILL，不必重拍相同现象替代缺口。补小物体慢移、物体停止、空场只变灯三个短组；记录TH012、CHANGED（HEX）、VALID/ERR和动作。建议固定相机/灯光各组重复3次；不是官方阈值。GLOBAL仅说明大范围块变化，不能自动认作识别出了光照变化。CHANGED是块数，不是物体数。

作用：验证改进的适用范围和负例。当前只支持“提示更醒目”，尚无检测率提升或运动响应时间数字。

### 5 一段连续长稳观察

建议至少30分钟，记录准确起止时间与同一运行版本；静态、移动、灯光变化和模式切换应写入时间线。持续观察，保存起止及异常关键帧；记录B/S、延迟N/E起止，花屏/错位/冻结/回跳/黑屏次数及恢复动作。可留连续录像/自动日志作为补充，分段短片相加不能成为连续运行时长；30分钟也不是全部环境/PVT签核。

作用：补赛题明确的长期运行、缓存溢出和光线剧变要求。尚无持续观察证据时只能报告已见的短片现象。
