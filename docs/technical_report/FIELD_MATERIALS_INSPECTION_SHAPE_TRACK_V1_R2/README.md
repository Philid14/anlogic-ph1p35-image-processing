## 现场如何使用

1. 第1—3页确认版本、设备、整机照片与基础视频闭环。先确认图像随动作更新、模式和Logo正常。
2. 第4→5→6页连续记录“厘米长线标定→真正空台面学习→独立量具复核尺寸”；第7页补手选D/R。保留标定ID和背景ID，不能用同一把尺的标定成功状态代替尺寸精度验证。
3. 第8—12页采集颜色、红色LAST框、运动/恢复、连续运行与实时性。保留错误和失效，不能只选成功照片。
4. 第14—17页可复制，记样品、逐次数据、定时观测及原始素材索引；第13页核对回传。
5. 主控填写第18页工程资料、第19页最终功能及性能声明，第20页检查五部分材料是否齐全，再结束现场采集。

建议至少保留以下目录；名称可以调整，但索引必须能找到原文件：

```text
RUN_日期_序号/
  filled_workbook.docx       已填写记录册
  version/                  实际bit SHA、下载记录、设备与配置
  photos/                   整机、量具真值、各模式完整OSD及失败照片
  videos/                   原始动作、按键、标定、恢复和长稳片段
  raw_data/                 逐次读数、定时观测和事件记录
  engineering/              主控确认的图纸、源码版本及构建/时序资料
```

不要把原始bit、个人联系方式或无关私人画面混入公开演示材料；工程仓库保持现有Private状态。缺少设备或无法执行的项目填“未测/不可读/不可见”及原因，主控相应收窄最终指标声明。
