## 主控一次性需要提供的工程资料

现场人员重点负责第2—17页；主控负责第18—20页，尤其是以下未决项。资料可引用仓库已有文件，不要求重复制造图纸或日志。

1. **最终版本与功能**：实际下载SHA、最终源码/tag/TD入口及最终展示范围；红色LAST框和手选D/R是否保留，蓝色与内部同帧计时仍未集成时如何在正文说明。
2. **设计图的真实性**：实际框架装配/局部图、尺寸，实物HX1P35A与仓库HX1P35B_FT_40P_2/3/8图纸的版次关系；厂商参考图注明出处及实际连接，不能充当自行设计电路。
3. **工程与参数**：实际模块层次、数据流、时钟/复位/CDC、关键IO；相机配置和AWB/AE取舍，区分配置意图与实际读回。没有的读回数据标为未采集。
4. **完整构建证据**：匹配bit的工具版本、资源、P&R/STA原始报告、约束覆盖及保留警告。当前归档值为21103/21216 Slice、105/108 ERAM、25/40 DSP，setup WNS +0.111ns、hold +0.020ns、TNS 0、STA覆盖95.69%；它们是该构建结果，不是板上稳定性结论。资源余量仅113 Slice/3 ERAM，覆盖与FIFO/Gray/CDC风险仍需说明。
5. **5项归档输入哈希保留项**：89项Git内容一致，原始字节28项直接匹配、56项换行转换后匹配、5项仍不能独立复现。请提供构建保留原文件或LF规范化内容哈希与换行说明，不直接判成RTL改动。详情见[原核对记录](../INSPECTION_SHAPE_TRACK_V1_TEMPLATE_REVIEW_V5/TD_INPUT_HASH_CHECK.json)：`mc_to_user_interface.v`、`ph1p35_ddr/ph1p35_324_ddr_wrapper.v`、`hdmi_tx.v`、`vision/measure_background.v`、`td_project/camera_to_dsi_display.sdc`。
6. **真实开发经历及引用**：从颜色目标检测走向固定平台颜色筛查与薄工件测量的实际取舍、遇到的问题、改动前后证据；核实使用的厂商IP/参考工程/开源资料和最终引用，不把参考作品的性能挪到本项目。

## 完成采集后的写作门槛

第20页逐项勾选，并把第17页索引与原始文件一并回传。对每个量化结论，应能追到“RUN和bit→实际配置→样品与真值→原始读数/状态→照片录像→统计与限制”。成功、失败和未测均保留。

- 有重复读数但无独立帧身份：可报告定时读数可用比例和重复性，不能报告逐帧检测有效率。
- 没有可信刷新率或延迟仪器/原视频：保留配置、显示器自报及定性实时现象，量化指标标未测。
- 无法提供新候选实测：正文继续标待板测，不能仅因写作需要填写“通过”。
- 原因未明的异常：列出输入、现象、次数、恢复与影响；不能用单次成功抵消异常。

按以上收齐，当前版本已知的正文、图表、性能表和局限说明可直接成文。发生新版本/硬件/条件变化，或数据不足以解释异常时，仍可能需要有针对性的补测。
