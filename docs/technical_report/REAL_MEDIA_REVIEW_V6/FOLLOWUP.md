# 第六稿后还需要什么

目前已经可以形成**有真实实物和功能现象的技术文档**，不必等所有性能指标都测完才写。下一次提高说服力的重点是补少量可复现数据，将“画面可见”提升为“条件、真值、结果和限制完整”。独立量具真值、连续运行及具体bit身份不能从拍屏补算。

## 已补到什么程度

| 项目 | 本次新增依据 | 可以写到的程度 |
| --- | --- | --- |
| 实物装配 | 相机/横梁、补光、板卡/显示端照片 | 真实搭建已有；完整整机两角度和尺寸图仍缺 |
| 算法与Logo | 五种基础模式、阈值变化、Logo实拍 | 支持功能演示；不写实测60独立帧/秒 |
| 厘米标定 | R5失败、另一片段R3/CAL OK | 已有粗标定成功现象；无成功率、倍数尺度独立排查 |
| W/H及D/R | 原值与尺寸线、半径线，亦有NO VALID OBJECT | 标注运行；无精度、重复性或实际尺寸保证 |
| 背景学习 | 关键尺寸帧BG:NEED/CUT | 明确当前回退路径；学习改善尚未由这些画面证明 |
| 双区颜色 | DIFF/LIGHT/CHECK、两区RGB、色卡及红样品 | 支持状态解释；无标准色差或准确率 |
| TRACK | 红瓶盖多位置有框，移出后SEARCH/VALID0 | 支持动态跟随和撤销；无定位/滞后/杂红鲁棒性统计 |
| MOTION | 移动变化块、回落STILL/000 | 支持动态状态；无小慢目标和灯变的控制实验 |
| 变光与稳定 | 灯控制器操作及短片显示 | 定性照明变化；不能写长稳通过、AE完成或AWB定量恢复 |
| 新延迟候选 | 固定归档的数字、P&R、STA和bit | 同帧计时已集成并构建；无新面板实物值 |
| T/L分段与密集点阵 | 最新开发分支数字/中间布线记录 | 在研，不计成品或上板成功 |

## 最小补充任务

以下次数是便于写作的团队建议，不是官方合格线；失败与未测如实填，不要求全部成功。建议继续使用[现场记录册](../FIELD_MATERIALS_INSPECTION_SHAPE_TRACK_V1_R2/README.md)中的RUN/样品/标定/背景ID及索引。

| 优先级与任务 | 实际要做什么 | 回传什么 | 对文档的提升 |
| --- | --- | --- | --- |
| P0 绑定本批bit | 主控找回当时PROGRAM_SRAM所用文件，计算SHA256；确认是否整个素材确为同一文件 | 文件版本/tag/SHA及下载记录；找不到则保留未知 | 将已见功能归到准确提交；避免把旧片当新候选验收 |
| P0 独立真值 | 量具量一块哑光矩形和一个完整圆片；记录量法、分辨率、厚度 | 量具照片与真实W/H/D；同一次标定，中心/左/右各重新放3次的全部读数和无效记录 | 得到按轴/位置的误差、最大绝对误差和重复范围；不能用屏幕D/2验证屏幕R |

| P0 连续观察 | 实际使用的最终bit运行一个明确时间窗，建议先30分钟；分开记录运行时长和实际录像/人工覆盖 | 起止记录、B/S/FRAME/ERR，花屏/冻结/回跳次数、条件与恢复；无记录区间标出 | 支持有限条件、明确时长的稳定性陈述，而非笼统长期零故障 |

| P1 跟踪与运动负例 | 固定机位：慢/快红目标、移出/重现、杂红/双红；静置、小慢运动、单独灯变分组 | 连续动作与屏幕同场片，源字段、异常次数；可选原分辨率HDMI帧与人工真值 | 从单次演示推进到失效边界；有可靠真值后才能算定位误差/帧级滞后 |

## 文档还可以怎样改进

1. **确定最终展示版本后再收口。** 当前正文分别描述实拍、最新已归档候选和未签发开发分支，适合审阅。最后应由主控选定参赛bit，再把无关开发细节移到附件，主文聚焦真正演示的能力。
2. **把图组结论变成有分母的实验表。** 现图已经能说明输入、状态和失效；补真值及独立摆放后，可用一个误差表和少量位置对照图替代重复描述，报告会更紧凑。
3. **完善图纸与计时示意。** 同帧身份路径已有明确文字，最终可增加与生产接口一致的图；旧图4已标历史SHAPE结构，不能让它代替更新后的区域选择或延迟身份链。机械图和匹配电路图更优先。
4. **收敛局限而不是删除局限。** 将标定R5、BG未学习、近饱和CHECK、LAST滞后整理为“输入条件→现象→原因依据→恢复/限制”，评审能更快理解可靠性设计。缺少单变量对照时不唯一归因。
5. **完成正式提交检查。** 沿用锁定名称/简介并解释YCbCr→HSV、K3操作、应用扩展和蓝色缺项；主控按官网最终格式/大小/匿名/截止要求核对。当前模板限字和≤20条参考已检查，不能据此代替官网入口检查。

技术文档在本轮已有实际内容提升；剩余短板主要是证据和版本确认。补齐上表P0后，即使不增加新算法，也能显著提高主要性能表和第三部分的可信度。
