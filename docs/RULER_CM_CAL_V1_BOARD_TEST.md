# 厘米粗标定上板步骤

先烧录RULER_CM_CAL_V1目录中的新bit。进入CAL后应看到 **1CM RULER LONG TICKS**；若仍写1MM，加载的是旧版本。

1. 保持ORIGIN模式和现有CAL大框。尺子水平平放，刻度朝上，框内至少清楚看到五条厘米长线；尽量用无文字白纸作背景。
2. **短按并松开K4一次**，看到WAIT/BUSY后保持不动，等到CAL:OK / R3。整框搜索约54个采集帧，通常需保持数秒；不要连续重复按K4重启搜索。
3. 关闭CAL开关，保留尺寸测量开关。对应屏幕逻辑SW通常由0101变0100；这是屏幕逻辑位，不重新推断实体开关左右编号。K3/K4和开关含义没有重排。
4. 移走尺子，在同一平面放入单个工件，观察工件旁W/H标注。摄像头高度、焦距和角度不要改变，否则重做标定。
5. 用尺子先量一个工件，例如约50mm长的矩形，再比较屏幕结果。若约变成100mm或25mm，属于倍数误认，不应接受；重新对准厘米长刻线、清理背景再读。

首版定位是大致比例：毫米小刻线不必逐条看清，但厘米长线必须清楚；文字/其他重复图案、反光、模糊、斜尺或高度差会造成误差。
工件仍需与背景明暗可分，阈值/亮暗极性沿用现有测量方式。显示0.1mm不表示真实误差只有0.1mm。

如仍失败，请记录：1CM标题是否出现、R状态、尺子位置、刻度清晰度。R4表示对比度不足，R5表示未找到足够一致的长线，R6表示视频完整性异常，R7表示中途取消。
R6或B/S在稳态增长时，先保留画面和计数查视频流；不要以反复放宽标尺判据掩盖异常。

验收至少覆盖框的上/中/下位置、取走再放回、重复三次、独立已知尺寸工件；随后确认颜色、五模式、TRACK/MOTION未退化。

回滚：VISION_TRACK_MOTION_V1 / vision-track-motion-v1-candidate；历史bit不改，所有PR不自动合并。
