## 3. 稳态与故障记录

- 至少进行3次冷启动；每次在约5秒、30秒和持续运行30分钟时记录完整屏幕；尤其记录 B/S 和底部两行诊断的增量。
- B 是前600个采集帧内含写满事件的帧数，S 是之后的帧数；不是“溢出像素数”。第一段不能只看 S=0。
- 正常稳定使用中 S 增长、花屏、错位、混帧或帧身份与标注不符，均为验收失败，不能用仿真通过覆盖。
- 改变照明、快速移动目标、连续切模式各测试一次；记录前后计数，避免把启动遗留累计值误认为持续异常。
- 如需测试采集停止，采用板卡支持的停流/安全断电步骤；不要带电插拔 MIPI 排线。HDMI 时钟继续时，过期正目标标注必须隐藏。
- 重新复位后检查新会话身份及恢复，不能继续使用旧帧/旧 slot-generation 的标注。

底部第一行：S/F/G/L 为 session/frame/generation/slot，D/C/Q 为丢弃/取消/metadata fault 累计计数。
第二行 D/R/W/I/V/C/S/T/O 是 TARGET guard 的重复、乱序、错会话、身份错误、无效、取消、过旧、时间错误和超时计数。
显示刷新可以重复读取同一完整采集帧；F 未在每次刷新增长不等于丢帧。记录照片时间和数值增量后判断。
