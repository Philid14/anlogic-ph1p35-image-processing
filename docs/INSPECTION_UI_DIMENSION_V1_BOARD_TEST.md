# INSPECTION_UI_DIMENSION_V1 实板步骤

本版本保持颜色检测原理、原五算法和Sensor/ISP配置。新增显隐、透明文字、
统一字体和有限条件下的二维测量。软件图是合成预览，不能替代本表的实测记录。

## 烧录与开关

只选择本版归档的 camera_to_dsi_display.bit，核对 BUILD_INFO 中 SHA256。
不要沿用TD旧Runs中其他版本bit。开始将SWITCH四路置低电平，进入ORIGIN检查
摄像头、Logo/CNT和透明MODE/THRESHOLD/B/S。物理上下方向以实板为准；
这里的ON表示接3.3V的逻辑1，不凭未确认的丝印方向定义。

| SWITCH路数 | 原理图网络 / 引脚 | 功能 |
|---|---|---|
| 第1路 | SW0 / A4 | ON显示颜色框和全部颜色参数，OFF全部隐藏 |
| 第2路 | SW1 / B4 | ON显示尺寸；与颜色同时ON时，尺寸显示优先 |
| 第3路 | SW2 / E11 | 测量时OFF深色工件/浅底、ON浅色工件/深底；标定时选X/Y |
| 第4路 | SW3 / D11 | ON进入尺子标定，OFF离开并确认 |

新增K2（KEY1 / A9）：仅在尺寸标定界面，短按间距减4像素，
按住约0.7秒后间距加4像素并连续增加。K3五模式切换和K4各模式阈值语义保留。
开关经过同步/消抖，画面在帧边界切换，DDR有原有显示延迟。

## 先验收两项界面修改

1. 两测量开关都OFF：不得有左绿框、右青框和底部参数；五模式仍正常。
2. 仅第1路ON：颜色框和参数恢复；分类、RGB均值、ABS/L1/MAX/LIM12原理不变。
3. 第1路OFF：两框与四行一起消失，不能残留黑矩形。
4. 检查MODE/THRESHOLD/B/S和颜色文字：空白字点应显示底下原画面。
   字母数字同为等宽字体，安路Logo/CNT仍正常。浅底文字对比度可能较低，
   本轮按用户要求没有恢复整块黑底。
5. 颜色对比仍要求每个框完全落在单一色块内部，不能混入尺子、黑边和背景。

## 用现有45 cm丁字尺标定

不需要新买标定卡，使用尺子上可靠的0～100 mm或任意相隔100 mm的刻度对。
若尺子刻度不准确，最终结果也不会准确。测量面应与尺子刻度所在平面相同。

1. 固定摄像头，镜头尽量正对平台；固定焦距、相机高度和工件平面。
   测量区为x256～1023、y160～543。不要使用侧拍或大范围透视倾斜。
2. 第2/4路ON进入CAL；第3路OFF选X。将100 mm刻度段水平放置，
   平移尺子并用K2调整两端标记间距，使两个刻度分别对准两条端线。
   屏幕 `SPAN:nnnn PX` 是100 mm对应的像素间距。初始256不是已知标定。
3. 第3路ON选Y，尺子转成竖直方向，在相同平面按同样方式对齐100 mm刻度对。
   两轴都必须实际完成；界面切换不会自动判断刻度是否对齐。
4. 第4路OFF确认；只有本次标定访问过X和Y两轴且第2路仍ON，才显示CAL:OK。
   该确认是操作者对齐确认，不是软件证明。退出CAL后，第3路恢复明暗极性选择。
5. 使用另一段已知长度进行交叉检查，不能只用同一100 mm段验证自身。
   重复复位后须重新标定；移动相机/焦距/高度/工作平面也必须重新标定。
   重新进入CAL会取消当前有效标定，完成两轴后再次确认。

## 测量工件

1. 首轮用用户照片中的薄矩形片或薄T形连接片，单件平放。
   深色片用白色哑光背景；浅色片用深色哑光背景。避免木纹、硬阴影和直射反光。
   角码、合页轴、凸起塑料件存在高度投影，不用来宣称平面尺寸精度。
2. 第2路ON，第4路OFF；选择正确明暗极性。先切BINARY用K4调阈值，
   使外轮廓连续、工件和背景分离，再切ORIGIN观察标注。尺寸统计仍取原彩色亮度。
3. 工件完全放在黄色测量区内部，外边不要碰区界。边与画面X/Y平行。
   `SIZE W/H` 是轴对齐整体外包宽高。T形片只给总宽总高，不自动分解每段。
4. 将待测孔/槽移到中心十字线；`GAPX/GAPY` 是穿过十字的水平/垂直空隙。
   圆孔只有中心对准、平面正对时才能将相等截线解释为内径；槽孔、缺口、
   金属反光也可能产生间隙，不能因此认定为圆孔。没有自动寻孔/圆拟合。
5. 未标定单位PX；标定后单位MM，显示一位小数。0.1 mm只是显示步进，
   不是精度承诺。尺寸源于整像素边界，须用尺子/卡尺验证误差。
6. 移走、移入、转动物件，检查无旧框长时间残留。LAST标注前一完整采样帧，
   移动时有一采样帧的统计滞后和原DDR延迟，不应当成同帧动态跟踪。
7. 空区/过小轮廓/触边显示无有效工件；缺行等无效测量显示横线。
   多个物品会合并为一个外包框，不支持独立多目标测量。

## 稳定性及待填记录

记录bit/tag/SHA、板卡、供电、镜头、灯光、标定X/Y像素数、尺子刻度段、
实际参考尺寸、屏幕值、重复性、方向与位置。至少各测试10次并测多个位置，
避免只报告一次凑巧接近的数值。校准比例误差、畸变、阈值边界和高度误差独立记录。

连续运行30分钟，切换五模式/应用开关，改变光照；记录B/S和有无花屏/冻结。
B为前600采集帧异常桶，S为之后。S若持续增加，先处理视频流可靠性，
不能用尺寸数字正常替代无溢出验收。历史Gray指针约束风险本轮未修复。
