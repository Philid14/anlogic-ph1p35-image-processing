# INSPECTION_UI_DIMENSION_V1 实板步骤

本版本保持颜色检测原理、原五算法和Sensor/ISP配置。新增显隐、透明文字、
统一字体和有限条件下的二维测量。软件图是合成预览，不能替代本表的实测记录。

## 2026-10-30 实板操作更正（优先阅读）

原说明把逻辑SW0～SW3直接写成实板第1～4路，未验证物理顺序，表述不准确。
下面原设计步骤中的SW编号仅指RTL逻辑输入，不能据此认定实板位置或拨动方向。
用户四张照片及逐路独立拨动反馈，目前支持以下操作对应；OFF/ON沿用用户描述：

| 用户称呼的物理路数 | 用户OFF位置的效果 | 用户ON位置的效果 |
|---|---|---|
| 第一路 | CAL时Y轴；RUN时BRIGHT | CAL时X轴；RUN时DARK |
| 第二路 | 尺寸界面启用 | 尺寸界面关闭，当前露出颜色比对界面 |
| 第三路 | 尺寸启用时进入CAL | 退出CAL进入RUN；两轴访问后会确认 |
| 第四路 | 未确认 | 第二路ON时再将第四路ON，颜色框和参数不变；显隐测试未通过 |

前三路是界面行为对应，尚无原始GPIO采样。第四路不能按排除法认定为颜色开关，
也不能由此断言开关损坏。构建IO报告确认逻辑SW0实际约束到A4；实板物理对应仍需核对。
详见[本次反馈记录](INSPECTION_UI_DIMENSION_V1_BOARD_FEEDBACK_2026-10-30.md)。

使用当前bit先验证尺寸的最短步骤：

1. 确认ORIGIN能看见摄像头下移动的白纸/工件，排除把屏幕反光当成实时图像。
   固定俯视、同一工作平面，白色哑光背景上放单个深色薄矩形片。
2. 第二路OFF、第三路ON、第一路ON：应为尺寸RUN和DARK。切BINARY，在RUN中用K4
   调整阈值，使工件与背景清楚分离；完成后回ORIGIN。不要在CAL中同时调二值阈值。
3. 第二路保持OFF；第三路OFF进入CAL；第一路ON选CAL X。将丁字尺上相隔100mm的
   刻度放在摄像头工作面，水平摆放，用K4短按-4px、长按+4px调整导线端点，真实对齐刻度。
4. 松开K4，第一路OFF选CAL Y；尺子在同一平面竖放，再对齐相隔100mm的刻度。
   松开K4，第三路ON退出确认，之后第一路ON恢复DARK。全程CAL使用ORIGIN。
5. CAL:OK仅表示访问两轴并退出，不能证明刻度对齐。照片中SPAN0256仍为默认值；
   只有实际按尺子完成两轴对齐后，才可验证MM。重新进入CAL或复位须重新完成标定。
6. 工件放在大黄色工作框内且不触边，边与画面水平/竖直方向平行。出现紧贴工件的
   检测框和W/H数字才算获得测量；大工作框本身不是识别结果。NO VALID OBJECT/横线不算成功。
7. 用尺子独立量出另一工件的真实宽高，记录10次屏幕值、均值误差和极差；旋转90度
   检查W/H交换，并在工作框内不同位置复测。移走应恢复横线，放回应恢复数字。
8. 孔/槽必须移到固定十字中心，GAPX/Y仅为两条截线；实心矩形没有有效GAP是正常现象。
   一位小数不代表0.1mm准确度。当前尚未获得实板尺寸精度数据。

## 烧录与开关

只选择本版归档的 camera_to_dsi_display.bit，核对 BUILD_INFO 中 SHA256。
不要沿用TD旧Runs中其他版本bit。开始将SWITCH四路置低电平，进入ORIGIN检查
摄像头、Logo/CNT和透明MODE/THRESHOLD/B/S。物理上下方向以实板为准；
这里的ON表示接3.3V的逻辑1，不凭未确认的丝印方向定义。

| RTL逻辑编号（非实板顺序） | 原理图网络 / 引脚 | 功能（逻辑高为ON） |
|---|---|---|
| SW0 / I_switch[0] | SW0 / A4 | ON显示颜色框和全部颜色参数，OFF全部隐藏；物理控制待验证 |
| SW1 / I_switch[1] | SW1 / B4 | ON显示尺寸；与颜色同时ON时，尺寸显示优先 |
| SW2 / I_switch[2] | SW2 / E11 | 测量时OFF深色工件/浅底、ON浅色工件/深底；标定时选X/Y |
| SW3 / I_switch[3] | SW3 / D11 | ON进入尺子标定，OFF离开并确认 |

使用已有K4（KEY3 / C7）：先进入ORIGIN，再在尺寸标定界面短按间距减4像素，
按住约0.7秒后间距加4像素并连续增加。切轴或确认前先松开K4。K3五模式切换和K4各模式阈值语义保留。
K1/K2是1.5 V上拉，未接入新功能。开关经过同步/消抖，画面在帧边界切换，DDR有原有显示延迟。

## 先验收两项界面修改

1. 逻辑SW0/SW1都OFF：不得有左绿框、右青框和底部参数；五模式仍正常。
2. 仅逻辑SW0 ON：颜色框和参数恢复；分类、RGB均值、ABS/L1/MAX/LIM12原理不变。
3. 逻辑SW0 OFF：两框与四行一起消失，不能残留黑矩形。该物理显隐验收目前未通过。
4. 检查MODE/THRESHOLD/B/S和颜色文字：空白字点应显示底下原画面。
   字母数字同为等宽字体，安路Logo/CNT仍正常。浅底文字对比度可能较低，
   本轮按用户要求没有恢复整块黑底。
5. 颜色对比仍要求每个框完全落在单一色块内部，不能混入尺子、黑边和背景。

## 用现有45 cm丁字尺标定

不需要新买标定卡，使用尺子上可靠的0～100 mm或任意相隔100 mm的刻度对。
若尺子刻度不准确，最终结果也不会准确。测量面应与尺子刻度所在平面相同。

1. 固定摄像头，镜头尽量正对平台；固定焦距、相机高度和工件平面。
   测量区为x256～1023、y160～543。不要使用侧拍或大范围透视倾斜。
2. 逻辑SW1/SW3 ON进入CAL；逻辑SW2 OFF选X。将100 mm刻度段水平放置，
   平移尺子并用K4调整两端标记间距，使两个刻度分别对准两条端线。
   屏幕 `SPAN:nnnn PX` 是100 mm对应的像素间距。初始256不是已知标定。
3. 逻辑SW2 ON选Y，尺子转成竖直方向，在相同平面按同样方式对齐100 mm刻度对。
   两轴都必须实际完成；界面切换不会自动判断刻度是否对齐。
4. 逻辑SW3 OFF确认；只有本次标定访问过X和Y两轴且逻辑SW1仍ON，才显示CAL:OK。
   该确认是操作者对齐确认，不是软件证明。退出CAL后，逻辑SW2恢复明暗极性选择。
5. 使用另一段已知长度进行交叉检查，不能只用同一100 mm段验证自身。
   重复复位后须重新标定；移动相机/焦距/高度/工作平面也必须重新标定。
   重新进入CAL会取消当前有效标定，完成两轴后再次确认。

## 测量工件

1. 首轮用用户照片中的薄矩形片或薄T形连接片，单件平放。
   深色片用白色哑光背景；浅色片用深色哑光背景。避免木纹、硬阴影和直射反光。
   角码、合页轴、凸起塑料件存在高度投影，不用来宣称平面尺寸精度。
2. 逻辑SW1 ON、SW3 OFF；选择正确明暗极性。先切BINARY用K4调阈值，
   使外轮廓连续、工件和背景分离，再切ORIGIN观察标注。尺寸统计仍取原彩色亮度。
3. 工件完全放在黄色测量区内部，外边不要碰区界。边与画面X/Y平行。
   `SIZE W/H` 是轴对齐整体外包宽高。T形片只给总宽总高，不自动分解每段。
4. 将待测孔/槽移到中心十字线；`GAPX/GAPY` 是穿过十字的水平/垂直空隙。
   圆孔只有中心对准、平面正对时才能将相等截线解释为内径；槽孔、缺口、
   金属反光也可能产生间隙，不能因此认定为圆孔。没有自动寻孔/圆拟合。
5. 未标定单位PX；标定后单位MM，显示一位小数。0.1 mm只是显示步进，
   不是精度承诺。尺寸源于整像素边界，须用尺子/卡尺验证误差。
6. 移走、移入、转动物件，检查无旧框长时间残留。LAST标注前一完整采样帧，
   移动时有一采样帧的统计滞后和原DDR延迟，不应当成同帧动态跟踪。
7. 空区/过小轮廓/触边显示无有效工件；缺行等无效测量显示横线。
   多个物品会合并为一个外包框，不支持独立多目标测量。

## 稳定性及待填记录

记录bit/tag/SHA、板卡、供电、镜头、灯光、标定X/Y像素数、尺子刻度段、
实际参考尺寸、屏幕值、重复性、方向与位置。至少各测试10次并测多个位置，
避免只报告一次凑巧接近的数值。校准比例误差、畸变、阈值边界和高度误差独立记录。

连续运行30分钟，切换五模式/应用开关，改变光照；记录B/S和有无花屏/冻结。
B为前600采集帧异常桶，S为之后。S若持续增加，先处理视频流可靠性，
不能用尺寸数字正常替代无溢出验收。历史Gray指针约束风险本轮未修复。
