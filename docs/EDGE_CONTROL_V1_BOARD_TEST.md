# EDGE_CONTROL_V1 上板步骤

状态：candidate构建/资源见BUILD_INFO，真实功能与30分钟稳定性待用户上板。本版本默认EDGE、阈值080，Exposure1990/VTS1000/HTS1600/Gain15.75×/BLC15/AWB_V2固定。

## 按键与烧录

1. 使用PROGRAM_SRAM下载 `D:\anlogic_formal_project\artifacts\bitstreams\EDGE_CONTROL_V1\camera_to_dsi_display.bit`，等待3–5秒；右上角应显示 `MODE: EDGE` 和 `THRESHOLD: 080`。原安路Logo/CNT仍存在。
2. 按键对应用户提供的HX1P35B_FT_40P原理图：**K3（KEY2/B9）切换模式；K4（KEY3/C7）短按释放阈值减10，长按约0.7秒加10一次**。按住不会连续调节，长按释放不会再减10。每次操作后完全松开至少20ms。不操作K1/K2或复位/配置键。
3. 原N2/J14是扩展GPIO，本版本已改接真实K3/K4。旧Exposure/Gain按键请求被断开，按键只控制算法。若实板丝印/版本与提供原理图不同，先反馈板上标识和照片，不据此推断Sensor故障。

## 模式切换

固定摄像头、光照、显示器以及手机拍屏曝光/白平衡。K3重复执行ORIGIN→EDGE→ORIGIN，至少20次。ORIGIN应为当前AWB后的彩色图，EDGE应为黑底白边；右上角文字随对应帧变化。应看不到半幅混合、周期性错行/撕裂或HDMI断连。模式请求只在输入帧通知处提交，经过DDR缓存后才显示，存在正常帧级等待，不要求按下同一瞬间文字改变。

## 阈值与弱光重点

- 先在固定室内场景依次记录80、60、40、20：从80到60/40/20分别短按K4两次/再两次/再两次。每次松开后查看OSD确认值。
- 上调使用一次约0.7秒长按加10，必须完全松开再长按。比较100、120、160；到达250后继续长按应停在250，10处继续短按应停在010。
- 再选择EDGE_V1在80时弱边缘不足的低光场景，以同一灯光/位置比较80→60→40→20，记录恢复的真实轮廓、噪声假边缘、大片白杂点以及始终无法恢复的轮廓。低阈值提升灵敏度，也可能显示更多噪声；不把白点增多当作效果更好。
- 在ORIGIN模式调阈值：文字应更新但彩色主体应保持；再切EDGE核对新阈值。这是检查阈值控制未改Sensor的实拍步骤，RTL端已有冻结表/请求隔离证据，不等同于实板寄存器读回。

## 稳定性与已知边界

连续至少30分钟，期间反复切换模式与调阈值，并做明暗变化。记录安路Logo/CNT、720p行列、闪烁、缓存异常表现及HDMI连续性。没有仪器统计时填写观察结果，不填写虚构的零溢出。

Sobel仍为640点水平采样、每结果复制两像素，前两行/每行首4像素清黑；保留约右移2像素/下移1行的因果核偏移。Original的原像素排列不改变；两路输出拍数与视频流坐标一致，但不会因此消除已有核中心偏移。

新文字叠在DDR前，会成为图像的一部分；即使缓存重复/延后显示，文字跟随该帧。现有DDR的整体长期稳定性仍需实测，不能用文字缓存方案宣称DDR不会撕裂。
