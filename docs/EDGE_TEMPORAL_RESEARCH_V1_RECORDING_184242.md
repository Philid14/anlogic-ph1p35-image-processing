## D. 异常、根因判断与下一步

### FIFO及其他错误

`design_top_wrapper.v`将`{read_underflow_sync,write_overflow}`送入记录。sticky=1明确对应**写侧溢出监测**；`video_in.v`在armed后且非FIFO reset时，`I_camera_valid && probe_full`置位，系统复位清除。

本批采样前该标志已经置位，8帧未改变；不知道具体触发帧、是否发生于启动、是否反复发生。ROI tap在DDR写FIFO之前，所存RGB及其CRC正确不等于下游FIFO/HDMI始终无异常。捕获数量、页恢复及post重建未发现错误，但**不能完全排除视频流/CDC异常**，既有Gray指针约束覆盖缺口也仍未处理。本轮未发现可直接提交的确定RTL功能修复，不修改正式链路。

### 证据等级

| 假设 | 当前支持程度 |
|---|---|
| 输入帧间变化 | 真实pre RGB直接测得，确认存在 |
| AWB引入额外变化 | 实际gain及精确反事实重放确认有影响；不能解释全部变化 |
| Sobel跨阈值/NMS选择敏感 | 真实RGB经旧整数模型重放得到明确翻转，非实板内部波形直采 |
| 四跳放大输出变化范围 | 同输入既有模型对照支持 |
| Sensor噪声 vs照明 vs真实微动 | 未分离；目标手持，不能排除真实微动 |
| 真正纸边峰位跳动 | 未取得可辨认边界及标注，仍未量化 |
| 编码页/打包恢复错误 | 全CRC及重建通过，本批无此类证据 |
| FIFO/CDC/时序风险 | 写侧历史溢出已记录；发生时刻/复发未知，不能排除；STA本轮未改未重跑 |

最支持的算法机制是：**AWB前真实像素变化已经存在，AWB小幅变化可额外影响临界响应，差分/门限/NMS及有限连接使局部变化转成不稳定的二值响应。** 这解释了早期Sobel即可闪烁、后续连接可扩大变化范围；但还不能宣布现实世界变化的唯一来源已经定位，或整个显示链的异常已排除。

### 最小下一次实板步骤

1. **先定位，先拍预览，再录长编码。** 把相机固定，黑白纸边用胶带/支架固定，避免手持。让竖向分界穿过画面中心：采样范围仅画宽45%–55%、画高47.78%–52.22%，不是整个中央大区域。
2. 沿用同一个诊断bit重新PROGRAM_SRAM；立即K3切ORIGIN，拍下编码出现前的完整屏幕短录像或照片，必须同时看见绿框与穿框边界。绿框尺寸仅约画宽10%、画高4.44%，不要等编码出现后找框。
3. **若始终看不到绿框，先提供这段预热ORIGIN短录像，不要求再盲录整轮101页。** 先核对bit、模式、捕获时刻及实板显示/采样坐标映射；静态代码一致不足以替代该证据。若来不及预览，定位固定好后再次重新编程。
4. 同时拍清预热诊断面板，观察重置后FIFO标志何时置位。现有sticky无法计重复事件；若持续出现，再单独设计带事件次数/首事件帧号的最小诊断，**本轮未修改RTL或生成该固件**。

优先级：**定位与完整性复核 → 固定真实边界、多次burst及运动对照 → 再选时间稳定或阈值/NMS/连接优化。** 目前可研究临界判决机制，尚不能在多帧投票/保持、阈值策略和NMS/连接改法之间作画质与拖影的可靠取舍。不开发EDGE_TEMPORAL_V1、不生成正式优化bit。
