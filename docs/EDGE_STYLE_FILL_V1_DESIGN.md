## 现有轮廓为什么不能直接当闭合区域

现有 EDGE 是 640 横向采样、每样本复制到 1280 输出。Gaussian/Sobel/NMS/四跳
采用因果窗口，显示内容中心相对当前拍为 x−14原图像素、y−7行，边界有无效黑区。
四跳仅连接已有弱候选，不能凭空恢复无梯度缺口；NMS 本身可能断开轮廓。
时间保持使用上一帧 raw Q 与当前支持，可能产生短时双线，不提供闭合性。
因此不能把最终 EDGE 与未移位 RGB 直接叠加，也不能按它无限翻转扫描线内外。

## 精确定义

在 AWB RGB888 的原1280点网格，对当前像素及左、上、左上构成的2×2邻域：

1. 每通道取高4位，计算4样本最大值−最小值。
2. 三通道跨度均≤2时，判为**局部同色区域**，各通道取四像素四舍五入均值。
3. 任一通道跨度≥4时，输出黑色边界；这不是 Sobel 或全局物体轮廓。
4. 中间不确定区域不混色，退回当前RGB。
5. 区域均值/退回RGB均以高2位映射到0/85/170/255，形成64色块填色。
6. 首行/首列没有完整邻域，直接当前RGB调色板退化，不读取旧帧作邻域。

**这是有界局部区域风格化，不是完整闭合轮廓、连通域或洞填充。**
区别于仅颜色映射：同色区域输出依赖四个真实像素的均值，且高对比区域有独立
边界判定；区别于BINARY：使用RGB三通道而非亮度单阈值，区域内部保留色彩。
不识别物体、不承诺整个人脸/杯子统一纯色；渐变跨调色板会分段，小目标可能被描黑。
同亮度异色仍可被RGB跨度检出。无递归连接，一处扰动最多改变4个相邻输出位置，
不存在缺口导致整行/整帧填充泄漏。没有帧历史，因此没有算法性跨帧拖影；量化边界仍会闪烁。

## 集成实现

三位mode + 两个8位阈值，共19位整包CDC；0/1/2/3保持原含义，4=STYLE。
K3：`EDGE→ORIGIN→GRAY→BINARY→STYLE→EDGE`；保留首次进入ORIGIN的习惯。
K4在STYLE忽略，EDGE/BINARY仍各自保存短−10/长+10阈值，OSD STYLE阈值留空。
新分支全时运行，用原27拍窗口对齐；既有EDGE算法及历史资格不改。
STYLE使用原1280网格，局部描边锚定当前像素（边界向右/下最多1px），不继承EDGE中心偏移。
预计增加两行RGB RAM、数百至约千Slice，实际以布局布线为准；不新增帧缓存、反压或有效拍。
Sensor/ISP、原四模式、Logo/CNT、B/S、DDR/HDMI、PLL/SDC保持原配置。

`style_fill_96` 为5拍：同步RAM读与当前RGB寄存 → 分通道两对min/max/加法 →
全邻域min/max/和 → 跨度/均值调色板 → 判定输出。生产配置取ORIGIN延迟链
第22拍作为输入，5拍后恰好落在原27拍窗口，避免新增长96位寄存器链。
两行分别按y奇偶存储，读取上一行、写当前行，选中的读bank绝不同时写，
不依赖RAM同地址读写模式。左右接缝保留上一有效拍末像素，valid间隙不推进。
计数只随真实有效4像素拍推进，SOF将坐标复位（可提前或与首拍同拍）；
首行/列使用资格位屏蔽旧RAM，不清空大RAM。每行宽度是IMG_WIDTH/4，
不以可能提前/延后的last改变现有固定宽度坐标语义；last沿原流窗口原样对齐。
上游损坏帧不是本模块可修复的对象；B/S与系统完整性风险继续独立验收。
