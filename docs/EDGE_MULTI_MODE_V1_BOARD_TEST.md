# EDGE_MULTI_MODE_V1 实板验收

## 烧录与初始状态

1. 使用TD Programmer对PH1P35MDG324执行`PROGRAM_SRAM`，烧录`artifacts/bitstreams/EDGE_MULTI_MODE_V1/camera_to_dsi_display.bit`。
2. 摄像头、HDMI线、显示器和供电保持现有HX1P35A配置。上电等待5–10秒，确认HDMI锁定。
3. 正常默认状态应为`MODE: EDGE`、`THRESHOLD: 080`；黑底白边、右上状态框、`B:hhhh S:hhhh`、安路Logo和CNT同时可见。

## 模式与阈值

每次按键完全松开后再进行下一次操作。

| 操作 | 预期 |
|---|---|
| 第一次短按K3 | `MODE: ORIGIN`，彩色原图 |
| 再按K3 | `MODE: GRAY`，彩色物体呈现不同明暗灰阶，阈值行不显示数字 |
| 再按K3 | `MODE: BINARY`，画面只含纯黑/纯白，显示当前BINARY阈值 |
| 再按K3 | `MODE: EDGE`，恢复时间稳定边缘，显示EDGE阈值 |
| 第4次循环结束再按K3 | 回到ORIGIN，无非法空白模式 |

GRAY/BINARY检查：准备红色、绿色、蓝色和中性灰物体。GRAY模式下三者应呈现不同亮度且无彩色；BINARY模式下任意放大/拍照采样只能看到`(0,0,0)`或`(255,255,255)`，不能带颜色。

K4语义：

- BINARY下短按释放：阈值减10；长按约0.7秒：阈值加10一次；长按后释放不得再减10。
- EDGE下同样短减/长加。
- ORIGIN/GRAY下K4不得改变任何保存阈值。
- 范围10..250；到010后继续减仍为010，到250后继续加仍为250。

独立阈值检查：

1. EDGE下调到060。
2. 切换BINARY并调到150。
3. 切回EDGE，应仍为060。
4. 再切回BINARY，应仍为150。

## 切换与画面稳定性

在ORIGIN/GRAY/BINARY/EDGE间连续切换至少20轮。每次按键只允许切换一个模式，按住不得连续循环。正常现象是切换延迟为若干采集/DDR帧，不要求按下瞬间变化；不允许半幅旧模式/半幅新模式、行错乱、周期性撕裂、黑屏或HDMI失锁。

建议固定相机和照明，先对同一场景记录四种模式截图。ORIGIN色彩应与EDGE_TEMPORAL_V1的ORIGIN一致；GRAY/BINARY的像素坐标、分辨率和有效区域不得偏移；EDGE应保留原有时间稳定行为，不得退化成简单Sobel黑白边。

## FIFO、长期与光照

1. 上电后约5秒、30秒、120秒分别记录状态框中的`B`和`S`十六进制值。
2. 在BINARY与EDGE间切换并调阈值后再次记录；模式切换不应让计数跳变或清零，除系统复位外计数语义不变。
3. 连续运行至少30分钟，期间缓慢改变室内光照、遮挡/恢复摄像头、移动高对比度物体。
4. 若`S`增长，将其视为正式验收阻断项，先排查FIFO/DDR；不要用算法输出看似稳定替代流可靠性判断。

正常记录应包含：开始/结束时间、bit SHA-256、摄像头/显示器/线材、光照条件、四模式截图、K3/K4操作次数、B/S起止值、是否花屏/失锁/错位。

## 异常回退

| 现象 | 处理 |
|---|---|
| 黑屏或HDMI不锁 | 重新上电；确认显示器支持1280×720@60；仍失败则烧回EDGE_TEMPORAL_V1 |
| 花屏、错行、撕裂 | 停止模式操作，记录B/S；S增长时优先检查FIFO/DDR，随后烧回旧bit定位 |
| 某一模式无输出 | 确认不是仍按住K3，重新上电并单次短按；持续复现则回退 |
| GRAY有颜色或BINARY有中间色 | 视为功能失败，回退并保存拍屏 |
| 阈值切回后丢失 | 视为功能失败，记录操作序列和OSD截图，回退 |
