## 首要判断与测试顺序

1. **ORIGIN**：先看彩色主体、颜色和亮度是否与旧版一致；只允许对齐寄存延迟，不应变模糊或变成灰度。
2. **粗轮廓/双边**：用纸边、标签、盒子边缘和两条靠近线。每bit在020/040/060/080拍同位置，记录白带宽度、是否分开、主要轮廓最长断口。NMS首要成功标准是明显变细且主要轮廓无不可接受断裂，不是单纯白像素变少。
3. **复杂纹理**：同一织物/编织物；记录是否只变细、纹理仍密集，以及物体大轮廓是否更清楚。真实纹理没有被全部删除不等于失败。
4. **低照度**：重复用户原夜间场景，020/040/060/080逐档比较弱边、孤立白点、轮廓连接性。分别寻找旧/新版合理阈值，不仅比较默认080。降低阈值不能补回已缺失的采集信息，也可能增加噪声。
5. **横/竖/斜线与细线**：原像素45°及不同斜率、细文字笔画、亮暗反转边界；记录锯齿、单点缺口、细线完整性与平坦峰选择带来的定位偏置。640点采样和复制仍保留，不能要求1280画面一原像素宽边缘。
6. **遮挡、运动**：从明亮场景全遮光/局部遮挡再恢复，至少3次，检查没有旧帧整行/整列残留；横纵移动物体看轮廓连续、错行、行间拖尾、撕裂。
7. **控制和长稳**：至少20次ORIGIN/EDGE切换；在ORIGIN调阈值，文字更新而主体不变，再切回核对；反复短/长按、检查010/250。至少连续30分钟并改变光照，观察Logo/CNT、OSD一致性、720p及HDMI不断连。有仪器计数再填零溢出，否则填“未测/肉眼观察”。
