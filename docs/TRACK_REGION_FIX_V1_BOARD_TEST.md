# TRACK_REGION_FIX_V1 简要实板测试

烧录本版独立归档bit，先PROGRAM_SRAM。确认回归通过后再决定是否写FLASH。
本版未在开发机连接实板；下列均为待用户执行步骤。

1. 四路开关调到屏幕显示 `SW:0000`，K3切到 `MODE:TRACK`。
   不按K4；颜色比对和尺寸功能保持关闭。固定摄像头/灯光，在无红色
   字样、尺子或手部干扰的白/灰哑光台面测试。
2. **空台面10秒**：应无绿色目标框，`N:00000`、`VALID:0`。
   TRACK状态可能短暂保留LOST，但不应保留上个框。`ERR`应为0。
3. **放入单个哑光红瓶盖**（正面朝相机，宽度明显大于8个画面像素）：
   约3个完整采集帧后应出现紧靠红色区域的绿色框；本体仍保持原色。
   `VALID:1`，N非零。静置10秒，不应扩展到整幅画面。
4. **左右、上下缓慢移动**：框应跟随，X向右增大、Y向下增大，N在大小
   不变时应大致稳定。再到四角、再回中心。边界以4像素分组，少量台阶正常。
5. **拿走目标**：下个完整结果应N=0/VALID=0，框消失。再放回应重新获得。
   快速移动时LAST框可能落后约一采集帧；本版没有整帧前视或预测。
6. **旧功能抽查**：K3循环其余模式；开启颜色比较、尺寸CAL/RUN，检查框和
   K4仍按上一版语义工作。Logo/CNT可见，画面连续。B/S记录启动值后观察
   稳态是否继续增长；若增长，先记录完整性异常，不能仅凭TRACK可用验收。

参数均沿用十六进制 `LAST HEX` 显示：

|参数|本版含义|
|---|---|
|X/Y|选中区域包围框中心，源1280x720坐标；不是质心|
|N|选中连续区域的支持面积，4像素块累计；不再是全画面红点总数|
|FRAME|该LAST结果对应的采集帧号，随新采集帧递增|
|VALID|当前可显示目标结果是否有效；没有目标应为0|
|ERR|视频观察时序异常累计标志，正常稳态应为0|

本版针对单个实心红色物体。浅粉、细红线、红色圆环、大反光孔洞或多个
同尺寸红物体不是本版保证范围。若空台面仍出框，请记录一段空台面→放入→
移动→取走的完整屏幕视频，同时记录bit SHA与SW状态；这能区分背景误检
与检测后框的接线问题。不要把拍屏RGB当传感器原始RGB。

回退使用 `inspection-shape-track-v1-candidate` 的旧归档bit；不覆盖旧bit/tag。
