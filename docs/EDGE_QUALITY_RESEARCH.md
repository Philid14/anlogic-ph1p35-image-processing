## 问题证据与局限

- **已证实**：前轮NMS模型/RTL逐采样点一致；用户本轮实际上板确认边缘变细，但弱轮廓仍断裂，TH40较丰富也较杂乱，TH60/80更干净但缺轮廓。照片中的眼镜双轮廓、面部/头发碎线可见；OSD右侧有裁切，不自行给每张照片补认阈值，也不能把所有头发纹理称作噪声。未得到30分钟稳定性测量。
- **结构已证实**：当前gray逐分量floor，像素对floor平均；四RGB/拍变为两采样/拍（内部640×720），复制回1280。Gaussian4级、Sobel前4+NMS4+阈值1共13级；OSD2+pack1共16。梯度为13bit signed，L1幅值14bit，Gy向上，NMS方向/相等平台规则正确；阈值是逐点决策，没有空间连接。平均采样有不可逆信息损失，模型用两个不同RGB图产生完全相同pair-gray作为证明。
- **合理推测**：弱光、15.75×增益下的传感器噪声会使梯度波动；有限采样、Gaussian、NMS方向量化也可能损失细节。但无本摄像头ORIGIN原帧/噪声标定，不能量化各项占比或认定是硬件缺陷。照片不是原始RGB。
- 仓库/参考目录检索发现的`00_input.png`是旧合成标签/电缆图，并非摄像头帧；GUI预览、Edge拍屏和模型图均不当作真实输入。本轮输入全部为明确生成的合成RGB，不能据此声称真实人脸识别率或真实夜间画质已经改善。

## 独立软件实验

`tests/edge_quality_model.py`在此前已RTL验证的整数梯度模型上工作，不调用OpenCV默认滤波，也不复刻RTL地址/流水状态。29场景：前轮19类，加眼镜、脸轮廓、纸张、小文字、细曲线各两档噪声；固定种子20261017。新增场景沿轮廓调制对比度，叠加sigma4/8高斯噪声和行偏置，故不是本传感器噪声统计。

13方法×29场景×8门限20/30/40/50/60/70/80/100，共3016行CSV。包含原NMS、直接降门限、1/2/4/8跳、两种强点支持筛选、方向限制、4142/10000角度边界、完整8邻接软件传播。采用共同ROI、补偿因果坐标偏移；真值为无噪图NMS≥10，召回/精确率允许一内部采样点，平坦误检在距真值四点外统计。下表是13个含噪场景的逐场景等权平均，不是全像素加权，不是实际图像标注。

## 取舍

1. **选4跳、无附加强点筛选**。与2跳相比TH50多约2.81个百分点召回；8跳翻倍后级缓存/对齐，TH60只再约1.24个百分点，当前约78%Slice及小Setup裕量下不选。保留强点，沿8邻域弱候选最多传播4条边，不穿过NMS零响应，不凭空填线，也不进行闭运算。
2. 额外孤点筛选几乎未改变含噪图误检，且需要一层窗口；要求两邻居还会删除两点短笔画。故**否决**，不因构造孤点案例通过就宣称真实去噪有效。最终版孤立强点仍会保留。
3. 方向限制TH60召回约74.03%、精确率98.61%，相对无方向4跳收益很小却增加方向缓存和比较，并可能阻断拐角，否决。4142角度边界对本数据召回几乎无差异，保留已验证NMS。
4. 完整滞后具有不定长度/随机访问；640×720两位标签约45ERAM20K，另需访问状态/队列或多遍帧调度。朴素19bit节点队列最坏约8.76Mbit，不适合作为本轮流式附加模块。四跳只是有界近似，不能称完整Canny。
5. 1280全密度可恢复部分pair平均丢失的细节，模型的采样零空间例验证了这一点；但需四采样并行，现有Gaussian/Sobel/NMS历史容量约39680bit至少翻倍、运算支路也增加，且不解决低信噪比。无真实帧不能证明它优于先连接的投入收益，暂不实现；未伪造其综合资源。
6. 更强平滑/Median可能侵蚀眼镜和文字细线，前轮降噪研究已显示代价；本轮不同时混改滤波。局部噪声自适应缺本传感器原图标定，无法可靠定参，先保留人工高门限控制。Sensor和外部视频规格完全不动。

## 选定算法的精确定义与实现前预算

`weak = nms_keep && magnitude >= floor(TH/2)`，`A0 = nms_keep && magnitude >= TH`。

重复四次：`A(k+1,p)=weak(p) && [Ak(p) OR any_8_neighbors(Ak)]`。每层同时对齐传递weak，保留强点。相同帧的固定TH用于分类，之后仅缓存每采样两位{weak,active}。输出A4。构造强100+30个弱50长链，TH80时四跳只保留前5个链点，另一个孤立强点仍保留，远处无锚弱链丢弃；完整软件传播保留整31点链和孤立强点。此差异是明确限制。

每层两行320×4bit×2=2560bit；四层共10240bit，预计256 DRAM LUT，0新增DSP，ERAM推断以报告为准。布尔邻域每层3级（捕获、同步旧数据读、邻域OR/AND输出），共新增12拍；Original/config/标记同量对齐，Edge25拍、OSD2+pack1总28拍（旧16），不是已经测量的端到端延迟。预计后级逻辑≤400LUT、模块FF≤400，加原图/配置12拍最多约1296FF；总增量目标≤1200LUT6/≤1800FF/≤1400Slice，期望Slice约85%以内，最终必须看路由。

空间中心约(x−14原像素,y−7行)，相对NMS多8原像素/4行；首14行/左28原像素保守清黑，右/下不额外补样。分辨率、有效拍、DDR字数不变。每层边界mask随核增长，RAM不清零，以SOF/行水平carry重置及mask拒绝旧帧。完整720p必须逐拍验证；不能用小图验证替代宽度320拍/实际打包。
