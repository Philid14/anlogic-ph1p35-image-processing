# INSPECTION_PARTS_MOTION_V1 上板测试

这是待用户执行的流程，不代表已实板通过。使用本版归档bit和BUILD_INFO核对SHA，首次PROGRAM_SRAM，保留latency-performance-v1-candidate作同接线对照。

## 运动点阵

1. 开关按屏幕状态调到SW:0000，K3到MOTION；固定摄像头、稳定照明，空台面等待数帧。
2. 移动哑光工件，观察橙红点阵是否比旧粉点清楚：每32×16检测区内采用8px间距的3×3实心点，最多8个点。显示点密度增加，检测网格/TH12没有改变。
3. 点阵表示上一完整有效采集帧与更前一帧的区块变化，与LAST统计口径一致。它不是红目标框，也不是物体轮廓；移动边界两侧均可有点。
4. 工件静止、拿走后保持不动：经过后续完整帧，点阵应消失；首帧建立历史时不画。快速移动允许约一采集帧显示滞后。切回TRACK，绿色红色目标框功能保持。

## 标尺、背景和档位

1. 正俯视、固定高度，尺子和薄工件同平面。ORIGIN、测量CAL，屏幕SW:0101，至少五根厘米长线在框内；短按松开K4，等待CAL:OK。
2. 移走尺子和工件，关闭CAL，仅测量RUN，SW:0100。空台面短按K4学背景，等待BG:OK/AUTO12，再放工件。
3. 保持W/H档；若显示D/R，长按松开K4一次切回W/H。新增分段识别自动运行，不增加新的按键/开关组合。仍以屏幕SW位序为准，不按实体从左至右猜编号。

## T/L工件

先用哑光纸板剪一块大T/L验证，再测试金属件。单个工件完整落在测量区内、四周留空白；直边与画面水平/垂直对齐，T横梁水平。只允许上下两段稳定且互相嵌套的水平截面，不是任意轮廓重建。

| 标记 | 尺寸 |
|---|---|
| W/H | 工件整体宽/高，原功能 |
| S | 较窄竖段的宽度 |
| T | 较宽横梁的厚度 |
| A/B | 左/右伸出量；为零的一侧不画标签 |
| V | 横梁以外竖段的长度 |

采用分段轮巡标注以控制资源：整体W/H→竖段S/V→横梁W/T→左伸出A/T→右伸出B/T；补充页各保持32个采集帧，后续相位保留整体，再循环。没有左/右伸出的一页改为横梁，避免零宽假框。每页数字和尺寸线画在该部分对应位置，并显示VIEW提示；单位仍为MM或未标定时PX。不同页合起来校验H≈T+V、W≈A+S+B，末位可有舍入差。不是同时绘制七组文字。

- T上下翻转各测一次；L分别向左/右、横梁在上/下各测一次。记录七项中实际存在的尺寸，与尺子独立读数比较。
- 静置10秒，记录最小/最大和是否间歇回退；在区内左/中/右位置重复。首版分段横坐标为4px分组，另有图像噪声、背景、透视与标尺误差，显示0.1mm不代表精度0.1mm。
- 旋转T使横梁垂直、放斜或放复杂轮廓：不应硬套分段尺寸，应回退W/H；需要分段测量时先摆正。工件/文字过小应放大成像，避免标签拥挤。
- 测量普通矩形、圆瓶盖：矩形保留W/H，圆片长按K4到D/R后保留原直径/半径。新增T/L不是圆弧拟合。
- 金属反光采用已学空背景；若边缘完全饱和并与背景融合，不能保证恢复。换灯、移动相机后重新学背景/标尺，不把影子或整片背景误检当工件。

## 旧功能与稳定性

检查七模式、颜色对比、尺子、D/R、红色跟随框、Logo/CNT及透明延迟面板。5s/30s/120s记录LAT/F/N/E与B/S，连续运行至少30min，移动、拿走/放回工件并改变灯光。稳态异常计数持续增加、错行/花屏或延迟持续BAD均应先记录，不能以新尺寸可见替代整机验收。

建议回传：MOTION移动→静止10秒录像、T和L正放/翻转尺寸照片及尺测值、圆片D/R照片、bit SHA和CAL/BG状态。烧录到FLASH只保存固件，运行时标尺与背景仍需重新学习。本轮完成候选后停止，不自动合并或继续下一版。
