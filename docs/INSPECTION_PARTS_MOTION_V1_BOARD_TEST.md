# INSPECTION_PARTS_MOTION_V1 上板测试

这是待用户执行的流程，不代表实板通过。只烧录完成签发后的本版归档bit，按BUILD_INFO核对SHA，首次PROGRAM_SRAM；保留latency-performance-v1-candidate同接线对照。不得把自动Runs内历史bit当成本版。

## MOTION

1. 按屏幕状态调SW:0000，K3到MOTION，固定相机/光照。
2. 移动哑光工件，观察橙红点阵比旧粉点是否清楚：每32×16变化块按8px间距画3×3实心点，最多8点；原TH12/检测网格保持。
3. 静止或拿走后保持台面不动，后续完整帧的点阵应消失；恢复首帧重建历史。点阵是上一完整变化图，与LAST一致，约一采集帧滞后，不是红色目标轮廓或预测。切TRACK复核原绿色跟随框。

## 尺标和背景

1. 正俯视、固定高度，厘米尺与薄工件同平面。ORIGIN、CAL，屏幕SW:0101，至少五根厘米长线在框内；短按松开K4，等CAL:OK。
2. 移走尺子/工件，关闭CAL，仅RUN，SW:0100。空台面短按K4学背景，等BG:OK/AUTO12，再放工件。
3. 保持W/H档；若显示D/R，长按松开K4切回W/H。新增分段自动运行，不增加按键组合。按屏幕逻辑位序，不猜实体左右顺序。

## T/L分段

先用较大哑光纸T/L，再测金属件。单件完整落在测量区内，四周留空，直边平行画面横纵方向，T横梁水平。

最终R3同时标注W/H整体宽高、S竖段宽、T横梁厚、A/B左右伸出、V横梁外竖段长，零伸出侧不显示。尺寸线/文字在对应部位，所有量共用W/H的MM/PX单位，不再轮巡。

- T上下翻转，L向左/右且横梁在上/下各测一次。拍全尺寸，与尺子独立读数比较；检查H≈T+V、W≈A+S+B，末位可有舍入差。
- 静置10秒记波动/是否回退W/H；区内左/中/右重复。横向4px量化，0.1mm显示不是同等物理精度；小工件文字拥挤时放大成像。
- 斜放、横梁竖直、第三段/复杂轮廓或触边应回退W/H，不硬套分段。不是CAD/孔或圆弧拟合。
- 普通矩形保留W/H；圆瓶盖长K4到D/R，核对原直径/半径。
- 金属件先学空背景，真实边界过曝融合时仍可漏检；换灯/移相机后重学背景和比例，避免把阴影当工件。

## 旧功能及长稳

检查七模式、颜色比对、红色目标框、Logo/CNT、透明字体及B/S。AWB只等价改变计算结构，算法/参数保持；同一静态白/灰/彩卡对照回滚版与本版，不应有新增持续偏色。

延迟面板按最终要求常显，无新增按键/开关。SW5 BUZ/SW为蜂鸣器电路选择，SW6 DIG/LED为显示供电选择，不绑定新功能。

5s/30s/120s记录LAT/F/N/E和B/S，连续至少30min，移动/拿走/放回并改变灯光。稳态异常增长、花屏/错行或持续BAD先记录，不能以新尺寸可见替代整机验收。回传MOTION录像、T/L全部尺寸照片/尺测值、圆片D/R、bit SHA和CAL/BG/异常计数。

FLASH仅存固件，运行时标尺和背景仍需重学。完成候选后停止，不自动合并或进入下一版。
