## 判别项目

| 项目 | V2应观察的改善 | 限制/失败判定 |
|---|---|---|
| 白纸与中性灰大区域 | 绿/青色台阶和杂斑减少，保持中性明度色块 | 若ORIGIN已明显偏绿，STYLE不保证纠正；V2新增大面积色斑为失败 |
| RGB/CMY色块 | 色相较接近ORIGIN，避免独立RGB量化的突变 | 浅色低色度≤12会去饱和，非色彩校准；看ORIGIN能否区分再评价 |
| 灰度阶梯/渐变 | 明度档较V1丰富；仍有明确STYLE分层 | 色带仍存在；变成完全原图、或整片灰阶变白均需记录 |
| 西门子星、细线、小字 | 白色间隔和亮细线更完整，轮廓不向亮侧过度扩张 | 对焦/打印/传感器采样已丢失部分不能恢复；以ORIGIN实际可分辨细节作上限 |
| 普通灰色/彩色物体 | 保留色块化及暗侧轮廓，不是取消描边 | 等亮度异色边界可能不描黑；高频纹理不应全黑塌成一团 |
| 高光 | 输入未饱和部分不再像V1那样过早全变白 | ORIGIN已255的细节无法恢复；本轮未调整曝光/增益 |
| 平移/进入/移出 | 无跨帧历史残留、无错行或4像素周期接缝 | 实际DDR延迟仍有；持续拖尾/旧行污染/花屏为失败 |
| 原四模式/按键/OSD | ORIGIN/GRAY/BINARY/EDGE正常，MODE/阈值/Logo/CNT对应 | 原模式变化、参数丢失、帧内混合为失败 |
