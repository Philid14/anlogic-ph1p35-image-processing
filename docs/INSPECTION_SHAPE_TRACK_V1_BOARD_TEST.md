# 上板验收：反光测量 / 圆片D/R / 红色跟随框

使用本版归档bit及BUILD_INFO核对SHA，先PROGRAM_SRAM。保留RULER_CM_CAL_V1旧bit作为对照，不覆盖历史文件。候选尚未上板。

## 尺子和空背景（新增一步）

1. 固定摄像头正俯视；使用无纹理哑光背景，工件、尺子在同一平面。屏幕逻辑SW按0、1、2、3顺序显示，不按实体左右顺序猜测。
2. ORIGIN，启用测量与CAL，屏幕SW=0101。水平放毫米/厘米尺，至少5根清楚的长厘米线在CAL框内。短按松开K4，尺子不动等待CAL:OK（原约54采集帧整框搜索不变）。
3. 关闭CAL，保留测量，SW=0100。**移走尺子及工件，留空台面，短按松开K4一次**。BG从WAIT到OK，随后显示AUTO12。等待几帧后放入工件。不要放着工件学习背景。
4. 尺子比例标定、背景学习是两件事：CAL开时K4标尺，CAL关的ORIGIN测量RUN下K4短按学背景、长按切换W/H与D/R。K3仍切换模式；BINARY/EDGE中K4仍调阈值。重进CAL会清背景，完成后重新做第3步。

## 反光工件

单个矩形片/带孔金属片平放工作区，保持与边界有空白间隔。先用旧bit记录W/H是否消失，再用本版完成尺子及背景步骤，记录10秒内W/H有效率、最小/最大值和尺测长宽误差。缓慢改变金属表面反光角度；不要在换灯/移动相机后沿用旧背景。无物体时不应持续标出大尺寸。若整块台面被误检，先排除光照/阴影和背景学习错误。

本版是单平面粗测，不测高度，不承诺高反光完全饱和表面的真实边缘可恢复。抬起厚工件会因透视改变比例。

## 圆瓶盖

正面完整圆轮廓、无明显透视压扁、与背景有对比。放入工作区，在ORIGIN测量RUN下**长按K4约一秒后松开一次**，看到K4 HOLD: D/R。预期出现上方D、右侧R和从中心至右边缘的半径线；D约等于尺测直径，R约D/2。再次长按恢复W/H，之后测方块/菱形/L件。圆片移到工作区左/中/右各测3次，记录有效率、误差及重复性。此版不自动识圆，也不拟合局部圆弧；不要把方块/倾斜圆片在D/R档下的数字当真实圆径。

## 红色目标框

先SW=0000，K3进入TRACK。用单个饱和红色不反光色块，背景避免其他红色，等待几帧。应看到保留红色本体的绿色外框，框与LAST参数对应。

- 左→右、上→下慢移：框跟随，X/Y分别增加；再快速移动观察上一采集结果的允许短暂落后。
- 靠近/远离：N一般随可见面积增减，框大小相应变化。不是距离标定。
- 移出视野：最新无目标结果到来后框消失、N=0、VALID=0；放回后重新捕获。
- 遮挡与两个红物体：记录漏检及总框局限，不当成多目标识别。
- 暂停源：检查原有SOURCE STALE提示；重复DDR帧不冒充新结果。

截图示例LAST HEX X27F=639、Y167=359、N028BB=10427。FRAME更新、ERR不新增；B/S在启动稳定后5秒/30秒/120秒及30分钟记录，确认是否新增FIFO/视频异常。测试ORIGIN/GRAY/BINARY/EDGE/STYLE/MOTION、颜色开关、Logo/CNT仍正常，强光变化和模式切换不花屏。

回传至少：一张完成CAL/BG的矩形尺寸图、一张瓶盖D/R图、10秒TRACK慢移/消失重现录像；说明bit SHA及光照/背景。显示分辨率、数字精度和实际测量精度不是同一指标。

尺子比例和背景参照都是运行时状态，复位/重新烧录后应重新标定、学习；将bit写FLASH不等于保存这两个运行时结果。
