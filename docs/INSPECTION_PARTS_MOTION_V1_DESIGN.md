# INSPECTION_PARTS_MOTION_V1 / MAIN 设计与证据边界

基线6ad4f7cd / LATENCY_PERFORMANCE_V1；分支codex/main/inspection-parts-motion-v1；Draft PR31依赖未合并30。不假设main含依赖，不合并、不改队友独立RTL。最终功能以R3和BUILD_INFO为准；R0/R1/R2为保留的研发检查点。

## 运动点阵

原32×16区块灰度均值帧差、TH12/MIN3保持。粉色每块最多4px改为FF3000橙红色、8px间距3×3实心点，每块最多8点/72px。增加的是显示密度，不是检测分辨率。

原4096×8历史RAM拓宽为9bit，第9位保存变化状态，仍2 ERAM。只发布完整有效帧的变化图，坏帧清资格、恢复首帧重建历史；与LAST统计一致，约一采集帧观察滞后，重复HDMI刷新不增加采集历史。不是目标轮廓/运动预测。保持实际4PPC坐标和原公共31拍延迟。

## T/L同时分段标注

保留厘米尺、背景差/二值分割、3像素连续段和原行面积资格。复用每行包络，寻找两个连续、稳定、嵌套的水平区段，各至少6行、宽差至少3个4px桶、端点允许±1桶。第三段、渐变、内部断行、短段、ROI触边/坏帧拒绝补充结果，保留W/H。

适用单个薄工件、正俯视、轴对齐和共同标定平面，T横梁水平；L可左右/上下翻转。不支持任意旋转轮廓、CAD、孔/圆弧拟合或三维测量。反光使真实边界融入背景时仍可能漏检。

| 标记 | 含义 |
|---|---|
| W/H | 整体宽/高 |
| S | 窄竖段宽 |
| T | 横梁厚度 |
| A/B | 左/右伸出；零侧不标注 |
| V | 横梁外竖段长 |

最终R3在对应部位同时画各项尺寸线/文字，不再采用R2轮巡页。统一字库、透明底，复用原迭代换算器，增加五组数值存储与绘图选择，不复制七套除法器。所有量共用W/H的MM/PX单位；小工件文字可能拥挤，应放大成像。

分段和完整尺寸在同一源SOF发布，并由显示SOF锁存，帧中不变。沿用上一完整结果LAST，移动时约一采集帧滞后。横向分段4px量化，另受噪声、透视和标尺误差影响，0.1mm显示不代表0.1mm物理精度。原长K4的W/H↔D/R保留，D/R旁路T/L附加量。

## AWB计算结构等价优化

没有改变AWB_V2采样/统计、阈值、增益夹限/步进/更新策略或50拍RAM图像延迟。仅将真实720行配置中每帧启动一次的两路48/32位无符号除法改为精确串行计算；原厂IP文件不改，默认参数和小于64行配置仍用原IP。

每拍求一个商位，48步计算，done保持原生IP实际启动沿后49拍。720行计数器保证启动间隔至少720拍，满足至少50拍契约；不是可每拍启动的通用流水除法器。输入位宽、小数拼接和截断保持。

原IP只复位输出，在途计算/启动令牌不清除。初次串行试验因提前取消在途计算而失败，已保留；R1保留同样的在途语义与输出复位。311组数值与50个复位偏移已通过实际IP对照。完整AWB逐拍对照检查RGB、valid、提前SOF、tlast、ready、商值、R/B实际/目标增益及pending，最终必须进入通过的验证门禁。不是修改白平衡算法，也不声称修复原IP复位行为。
