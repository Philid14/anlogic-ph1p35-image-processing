# 最终作品原始需求摘录

来源：用户本地“最终作品实现/关于最终作品实现.txt”。以下是设计意图，不是完成情况或新增硬件操作授权。

关于最终作品实现:
我希望做成一个在固定平台主要实现以下两个功能:
（其中固定平台为一个铝型材搭建的长方体框架，在框架顶部放置摄像头俯视桌面采集，底部放置具有标准卡尺的置物平台，框架外采用遮光布遮光，内置可调光源并且在遮光布内侧粘贴反光材料）
1.颜色比对:将会有色差的色卡或物体放在置物平台一侧，另一侧放置标准色卡，将两种进行颜色对比，屏幕标定相应参数，给出差值等参数
2.二维工件尺寸标定:通过固定高度下摄像头对标准卡尺的采集，计算像素点对应尺寸，在置物平台放置工件，通过采集和之前的标准尺寸量化，标定工件各种尺寸，如长宽高，圆弧的内径外径等常用的CAD参数，并在屏幕相应位置上标定（初步规划只选用比较薄的工件，如果实现之后可根据三角关系计算，计算出工件高度，不过这部分先不考虑）

当前实现边界见TECHNICAL_REPORT_V0_1.md；高度测量仍不在当前范围。
