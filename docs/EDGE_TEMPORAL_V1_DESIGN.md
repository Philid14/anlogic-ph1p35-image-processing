# EDGE_TEMPORAL_V1：单采集帧梯度支持保持

角色MAIN；基线和范围见EDGE_TEMPORAL_V1_TASK。研究commit6d68d8b，独立FIFO监测commit399ed6a。不是算法最优证明，真实画质待上板。

## 选择与单一算法

令Q_t为既有Gaussian+Sobel+NMS+四跳结果，G_t为**未受NMS抑制**的同坐标Gaussian+Sobel幅值。输出：

`E_t = Q_t OR (Q_(t-1) AND [G_t >= floor(TH/2)])`。

只储存原始Q_t，**不储存E_t**，不递归延长保持。当前真实边缘不被删除、新出现无等待；上一帧像素仅在当前仍有梯度支持时补回。若Q连续两帧为0，即使支持一直存在，也不会再保留；当前梯度不够时立即释放。没有提高原高门限、额外Gaussian或多算法组合。

比较QUALITY、NMS弱候选保持、当前原梯度支持保持、三帧投票。仅NMS弱候选保持不能应对峰位切换；投票虽减少静态翻转，但合成8像素/帧移动线可被完全删除。原梯度支持方案模型收益值得一次上板，且只需一位历史/内部点。它会加粗或暂留部分响应，不声称全面占优。

6类12帧合成静态/斜线/2及8像素移动/出现消失，TH40/60/80，另有两份此前完整CRC验证的真实NPZ。所有对比统一排除前两帧；真实样本无轮廓真值，不以翻转减少单独宣布画质提升。真实输入NPZ按已归档SHA验证，原始解码链见研究PR#9提交58f3a6d中的报告。

## 空间与寄存对齐

保留现有NMS/四跳逻辑不改。NMS已提供与自身输出对齐、未抑制的O_center及O_debug_valid，按本帧low门限得到两位support。分类S5寄存后，通过4个edge_center_pair_delay，各自以与一跳link相同的3拍、上一行上一采样中心搬运支持位；行缓存每级80×8=640bit，四级2560bit，边界同6→8→10→12→14。

最终support与Q_t在相同输出拍、相同真实中心（约x−14/y−7）对应。不能用简单12拍寄存代替4行中心搬运。独立模型根据空间切片生成期望值；前14行/左28像素保留既有黑边，无新增卷积边界或像素数量变化。

保持器同步读历史、再寄存决策共2拍；Original/config/valid/user/last同步补2拍。Edge和Original由25变27拍，OSD2+打包1总计30拍，原28拍；**新增2个接收时钟周期、0整帧显示等待、0额外图像中心偏移**。历史算法仍依赖上一采集帧，但没有阻塞当前帧等下一帧。此为内部寄存延迟，非实测端到端时延。

## 历史RAM、身份、异常与复位

- 位于AWB后、DDR前，使用真实采集流的提前SOF；HDMI重复刷新不触发更新。身份语义为相邻两个完整采集SOF区间，而非显示帧号/循环DDR槽号。没有新增统一TEAM帧身份接口。
- 每帧320×720=230400个四像素拍，每拍2内部边缘位，历史460800bit。八拍打包成16bit，28800字，逐地址先读上帧，再写当前原始Q。
- 仅phase0同步读，phase7写；生产帧整除8，不存在同地址同拍读写碰撞。没有组合RAM反馈或全RAM复位；启动资格屏蔽未知旧位，完整当前帧覆盖后才能使用。
- 上一帧只有在拍数230400、行尾720、行长320且无监测错误时才可作历史。短帧、超长帧、错行尾、复位或高阈值改变后，历史失效；再完成一帧才重新启用。当前发现格式错误后立即停用后续保持，不能回收错误发现之前已经输出的像素。
- R0定向测试发现“重复一个EOL＋漏掉下一个EOL”能绕过仅看总数/位置的初版门禁。最终版增加pending_eol，逐行验证EOL先后次序，允许行尾与最后有效拍同拍或在其后消隐期到达，拒绝重复及下一行开始仍欠EOL。该修正不改变正常帧算法/存储/吞吐；R0虽路由时序通过，仍以功能问题拒绝，归档仅供追溯，不供上板。
- 同阈值ORIGIN期间仍计算真实Q，K3切回EDGE可使用对应上一采集帧；K4改阈值清历史资格，按键语义不改。帧内配置仍SOF锁存。
- MIPI尚无可用packet错误身份端口时，不能声称能检测所有传感器/PHY异常；已有FIFO/CDC风险独立保留。

## FIFO只读观测，与算法分开验证

写FIFO.full_flag接只读同域计数器，写使能、reset、DDR仲裁不改。每个采集帧只要出现`armed && !fifo_reset && write_valid && full`就记一个异常帧；同类事件跨帧可重复计数，不被sticky掩盖。两个16-bit饱和桶：前600采集帧B、之后S，均在系统复位清零；不是溢出beat总数或准确丢帧数。

状态区新增第三行`B:hhhh S:hhhh`，十六进制；MODE/THRESHOLD原两行、字库、安路Logo/CNT保持。计数在采集时钟域产生，OSD提前SOF原子锁存为历史状态，后随图像经过DDR；无新增CDC，也不宣称状态就是该帧首次异常。

本机无法测定真实稳态是否继续溢出。烧录后5/30/120秒记录B/S；若S增加，正式验收阻断，先定位FIFO/DDR再评价稳定算法。B非零且S持续0只能支持“本观察窗口未再记录稳态事件”，不能消除历史风险。计数饱和FFFF仍视为异常，不能当稳定。

Gray指针覆盖缺口仍独立记录。现有全局异步clock groups不改；应后续对实际FIFO Gray源寄存器至首级同步器做厂商支持的定向max-delay/bus-skew覆盖核验，再检查例外优先级及物理路径，不能用加宽异步例外掩盖。当前候选不声称CDC修复。

## 已知代价与上板验收重点

静态边缘可能从一内部点变为两点，小幅运动可能出现仅一采集帧的双线/增厚；当前梯度范围宽或背景纹理强时也可能多留杂边。8像素/帧移动合成场景未像三帧投票一样消失，目标消失且梯度消退时立即清除；不保证任意真实运动无拖影。

先检查ORIGIN/按键/Logo/OSD/连续显示及S计数，再同机位/固定纸边/眼镜对比QUALITY旧bit与新bit，TH40/60/80完全一致。固定手机曝光、白平衡、对焦，分别静止10秒、缓慢左右移动、快速移出；关注闪烁、峰位、线宽、杂边和消失响应。最后30分钟运行/光照切换，S若增加即停止画质验收。
