# 一键读尺与工件旁尺寸标注：实板验收

日期2026-11-01 / MAIN。只烧录本版归档bit并核对BUILD_INFO的SHA256。
本版仍待真实实板验收，模型/仿真通过不表示尺子已在实板识别成功。

## 最短操作

1. 固定相机俯视，固定焦距、高度、灯光。在工作面放浅色哑光底，确认ORIGIN确实显示摄像头下移动的尺子。
2. 按上一轮实板路数：第二路保持用户称“关闭”的位置，第三路“关闭”，进入带读尺框的CAL界面。
   本版标定不再使用第一路选X/Y，也不需要逐像素调整SPAN。第四路物理映射问题尚未解决，不依赖它标定。
3. 将丁字尺**带1mm短刻线的直边**水平放入中央框，黑刻线朝向相机。让每条短刻线穿过框中的虚线，
   至少包含16条连续、清楚的1mm刻线。黑字/数字不要压到扫描线，尺子不能反光、失焦或只有厘米长刻线入框。
4. ORIGIN下短按并松开K4一次。界面依次显示CAL:WAIT/BUSY，成功为CAL:OK；FAIL则重新摆尺再短按，
   不会把退出标定当成成功。按键触发的是下一完整采集帧，不是拍屏录像。
5. 成功后移走尺子，第三路拨到用户称“开启”的位置，进入测量。比例保留到复位或再次按键标定。
   深色薄片配白底时第一路“开启”选DARK；浅色薄片配黑底时第一路“关闭”选BRIGHT。
6. 用K3到BINARY，RUN中用K4调阈值，使单个薄工件轮廓与背景分离，再回ORIGIN。
   工件放在中央工作范围x256..1023、y160..543以内，不碰边，外边尽量平行画面X/Y。
7. 外包宽W标在工件上方，高H标在右侧，带尺寸线、延长线、箭头和MM单位；不再在底部列尺寸表。
   未成功标定时单位PX，不可当MM。工件移走/无有效结果时，旧尺寸线应消失并提示NO VALID OBJECT。
8. 要测孔/槽截线，将孔放到固定中心x640/y352。X/Y标在该开口附近；这只是两条截线，
   不是自动识别圆孔或所有孔中心。实心矩形没有X/Y标注是正常情况。

## 必须独立复核比例

水平尺自动读数仅直接约束X；本版X/Y共用比例，要求正俯视、近似等比例、尺子与工件处于同一平面。
用丁字尺独立确认另一已知长度（例如50mm），分别水平、竖直检验；不移动相机，不只验证本次被读取的刻度。
如果两个方向差别明显、测量误差随位置改变，不能宣称标定有效；应反馈水平/竖直读数和位置。
厘米线被误当1mm会产生约10倍尺度错误，必须先排除。算法无法从周期本身证明真实物理单位。

选择用户已有的薄矩形金属片，独立量出真实宽高。首轮避免合页轴、角码和凸起塑料件。
记录10次W/H、均值误差、最大值减最小值；旋转90度后W/H应互换，在中央与不同工作区位置复测。
测得0.1mm小数位不代表准确度0.1mm。尺子分辨率、像素采样、失焦、反光、阈值、透视和高度均影响结果。
初次建议记录一段“尺子入框→K4→CAL OK→移尺放片→W/H→旋转→移走”的短视频，能同时检查操作和标注。

## FAIL排查与原系统回归

- WAIT一直不结束：先看原图是否更新、是否有完整视频帧；不要通过重复退出CAL强制确认。
- FAIL：让黑色短刻线完整穿过扫描线，调好对焦和光照；不要只有数字/厘米刻线、木纹或高光。
  读尺允许2..16px/1mm，至少15mm连续区间；过小、过大、缺线、扫描结果不一致均可能拒绝。
- BRIGHT/DARK或二值阈值错误会影响工件分割，与读尺的自适应阈值不同。不要把背景轮廓当成工件尺寸。
- 动态移入移出会有前一完整采集帧结果的滞后和既有DDR显示延迟，本版面向静止工件，不宣称同帧动态计量。
- 切五模式、颜色/尺寸/CAL，检查Logo/CNT、原模式透明文字及原颜色比对规则保持。颜色与尺寸同时请求时尺寸优先。
- 连续30分钟及光照变化记录B/S、花屏/冻结；S若稳态增长，停止计量验收，先处理视频可靠性。
  FIFO/Gray约束历史风险仍未在本任务中排除。

回滚：重新PROGRAM_SRAM历史INSPECTION_UI_DIMENSION_V1 bit；无需修改任何源码、tag或Sensor参数。
