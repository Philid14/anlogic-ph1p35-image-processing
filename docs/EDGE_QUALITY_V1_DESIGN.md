# EDGE_QUALITY_V1 数据流与实现契约

角色MAIN；基线、候选比较和实现前预算见EDGE_QUALITY_RESEARCH.md。唯一主要变量是NMS后四跳连接，不叠加滤波/方向/曝光变化。QUALITY_ENABLE默认0，正式Top显式1且QUALITY_HOPS=4；关闭QUALITY恢复原NMS数据/时序。Gaussian和NMS模块源码完全冻结。

## 标签与时序

Sobel原S5在QUALITY路径中改为两采样点分类寄存，每点两位`{weak,active}`：weak为NMS保留且幅值≥floor(TH/2)，active为NMS保留且幅值≥TH；比较仍完整14bit，TH来自本帧运行时配置。高门限仍为OSD现有THRESHOLD值，K4步进/范围/默认80不变。分类沿用原S5一拍，未把8bit门限与梯度截断比较。

四个edge_link_pair_3x3串联，每级只读取上一级的active，不在自身当前行内反馈。因此一步严格对应图上的一条8邻接边；A4只保留通过≤4条弱候选边可到达某强点的候选。强点保留，零响应断口不被填补，无锚弱分量丢弃。不是完整连通域，不是无限滞后，不是膨胀画白。

## 每级两采样并行窗口

每拍对应内部点n=2g、n+1。L1捕获两点标签/坐标；L2同步读row1旧上一行、row2旧前两行并写当前row1；下一拍将已寄存mid复制row2。row1/row2各320×4bit，单读/单写，AUTO推断、无数组复位。总四级10240逻辑bit，新增8个历史行；既有Gaussian/Sobel/NMS历史数据独立不改。

L3两个中心分别是前一拍mid低样本m1（位置n−1）和当前mid高样本（位置n）。top/bottom保留前两点active，mid保留前两点weak/active。同拍/跨拍各八邻居都被包含，输出weak等于中心weak，active为中心weak AND（中心active OR 八邻active）。宽度仅1bit布尔组合适合直接在L3寄存，不采用14bit选择器/比较级。

valid/user/last每级无条件延迟3拍，数据只在窗口有效时输出。坐标只数有效拍；tuser可提前或同拍到来，均重置本帧坐标和水平carry。每行末清carry。边界按6→8→10→12→14依次增长，屏蔽不能完全来自本帧的窗口；数组旧数据不清零也不能泄漏到有效区域。正式宽度1280/4=320拍/行，不添加行内气泡或反压。

## Original、配置、OSD与打包

Gaussian4+Sobel前四级4+NMS4+分类S5一拍=13，再加四跳×3=12，Edge分支共25拍。Original仍来自同一AWB RGB，只调整原有寄存对齐长度13→25；状态区外RGB内容逐字节不变，未改其源、颜色或格式。9bit配置和valid/user/last同25拍；状态OSD再2拍，实际96→128打包再1拍，总28拍，旧16拍。新增12个MIPI接收时钟周期约200ns（基于名义59.995MHz报告值，非实测端到端延迟）。

配置仍在AWB提前SOF提交、随每拍延迟；旧帧在流水时不会取新配置。后级标签不需要再存TH，因为分类已按本帧门限完成，所有有效邻域只属于本帧。状态OSD仍在DDR前成为本帧像素；DDR后Logo/CNT保持。未修改K3/K4/CDC/字库/OSD位置、DDR/HDMI、PLL或SDC。

每完整720p帧仍230400有效96bit拍、172800个128bit字。tlast仍行尾，实际isp_top打包后行尾补1拍保持。因果中心约(x−14原像素,y−7行)，相对NMS额外8原像素/4行；首14行/每行左28像素黑，右/下不追加数据。画面边缘损失与坐标偏移必须在公平ROI比较及未来LATENCY适配中说明。公共TARGET/LATENCY身份接口没有在本轮接入，队友独立工程未改。

## 已知画质限制

只救回有足够梯度且距强点≤4跳的弱段，不恢复NMS已抑制/采样已丢失的信息。单个强噪点保留；低高门限均低时可能沿噪声扩散，TH40不保证比旧版干净。640采样和两像素复制、L1方向偏置、固定曝光/高模拟增益噪声均仍存在。真实画质由实板验收，不以合成召回率替代。
