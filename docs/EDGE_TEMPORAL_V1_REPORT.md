## 1. 选择了什么、为什么

采用**单采集帧、当前梯度支持的非递归边缘保持**：

`输出_t = QUALITY_t OR (原始QUALITY_(t-1) AND 当前同坐标Sobel幅值 >= floor(TH/2))`。

历史只存上一采集帧的原始QUALITY位图，不保存已保持结果。当前边缘全部保留，新出现无需等待确认；补回点必须在本帧仍有梯度支持，无支持立即释放，连续两帧原始Q为0则不再延续。未改高/低阈值定义或Sensor/ISP参数。

比较QUALITY、仅NMS弱候选保持、原梯度支持保持和三帧投票。仅NMS弱候选保持不能解决峰位切换；三帧投票在合成8像素/帧移动边缘上可把轮廓全部抹去。所选方案只需一位历史/内部点，能保留当前检出，值得做一次实板验证。模型没有证明它最优。

## 3. 拖影、噪点与已知限制

- 慢速移动可能保留上一位置一采集帧，出现短暂双线或增厚；背景纹理/噪声仍有梯度时也可能多留一帧杂边。
- 历史不递归延长，但原始Q反复出现会反复刷新保持；不保证任意现实运动无拖影或噪声完全消失。
- 当前检出的Q不被删除；一直没有强种子、原始Q持续为0的弱轮廓不会凭空补出。640内部横采样、Gaussian/NMS/四跳的原有局限仍在。
- 现有真实ROI目标手持、未辨认出清晰黑白分界，不能在缺少真值时判定完整度/背景误检/实际白线位移。实际收益由上板A/B决定。

## 6. FIFO/CDC风险：尚未排除

先前真实ROI的写侧历史溢出sticky=1，没有首次时刻及重复事件证据。本轮新加**只读异常帧计数**：`B:hhhh`为前600采集帧，`S:hhhh`为之后，每帧出现write/full至少一次就加1，饱和FFFF。它不是丢beat总数；FIFO写使能、reset和DDR仲裁未改，也没有虚报已完成FIFO修复。

本机无法确认真实稳态是否反复溢出。上板若S增加，作为正式验收阻断项，先查FIFO/DDR；不能以滤波输出更平稳替代流可靠性验收。

最终exception报告仍显示两组Gray指针max_delay（14.700ns和13.033ns）各18条路径全部Ignored，被既有clock groups覆盖。**覆盖缺口已复核，未修复；没有实测证据证明Gray偏斜超限或它造成白线抖动。** 后续需要独立、定向处理例外优先级和物理Gray路径覆盖，不能随意放宽全局异步约束。
