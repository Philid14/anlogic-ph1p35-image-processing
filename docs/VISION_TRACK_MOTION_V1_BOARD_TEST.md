## TRACK

- 用红色纸片/卡块、灰白背景。等连续三个可靠帧后观察ACQUIRE→TRACK；标记应贴着**当前红色像素**，沿左右/上下移动时随物体走。
- LAST HEX X/Y 是最近完整帧的包围框中心，单位像素；N是匹配像素数；FRAME是采集帧号。全部HEX，不是毫米。例280(hex)=640(px)，168(hex)=360(px)。
- 从左向右移动时X应增加，上向下移动时Y应增加；无红色时N变0、VALID变0，标记立即无可匹配像素，不应留下旧框。
- 快速移出/移入：TRACK→HOLD→SEARCH或重新ACQUIRE；HOLD只保留确认状态，不保留消失处的色块。相近红色背景/多个红物体会合并统计，不能据此说是多个独立目标。

## MOTION
