# EDGE_STABILITY_DIAG_V1 实板判别实验

状态：2026-10-18，**实验计划，尚未执行；本轮无新诊断bit。**
现有candidate可做A；B/C/D需要另行完整构建、STA、bit归档及唯一commit/tag后烧录。
不能把软件强制信号当作已经装入FPGA的开关。正式参数、按键和720p规格不变。

## A. 先做无需新固件的记录

1. 用现有QUALITY bit，核对SHA256 `629ACAA828EF8151DED0261779ED8B91F0FA618EED66DD46C72D6E799ADCC9D5`。
2. 三脚架固定相机，先用印刷直线/小字/眼镜静物，脸只做第二场景（呼吸、表情和眼镜反光不是严格静止）。镜头、机位、显示器不动。
3. 分别在稳定日光/已确认无明显频闪的直流光源、原室内灯光下记录；亮度尽量接近，记录照度条件，不能改变传感器曝光或增益去“校准”。
4. 固定TH60记录ORIGIN至少10秒，再EDGE至少10秒；TH40/80独立记录，不在同一个统计序列按键切换。旧CONTROL/NMS做同条件复现。
5. 优先HDMI原生1280×720采集，不缩放、不插帧、锁采集设置。手机锁曝光/白平衡仅为现象记录；显示器扫描、摩尔纹、手机滚动快门可引入伪闪烁，不作原始RGB证据。
6. 现有CNT属于显示侧动态叠加，不用它直接区分摄像头新帧与重复显示帧。记录刷新和重复帧限制；无采集身份时，不声称准确相机帧闪烁率。
7. 对照录像记录是局部线段变化、全轮廓平移、整行错位、撕裂还是块状错误。仅凭这些形态不作排他归因。

这些记录能约束灯光/物体微动假设，仍不足以排除控制或CDC异常。

## B. 优先诊断固件：固定数字RGB + 真实视频控制

### 接入和回退

- 从准确QUALITY候选另开诊断分支；在AWB之后的`edge_control_stream`内部，仅为`u_edge.I_tdata`增加编译期固定RGB选择。Original的`original_p`继续接真实AWB数据，保留其内容和既有延迟。
- RGB替换为确定函数；`valid/user/last`保留实际AWB输出，严格禁止用独立计时器在本实验中生成这些控制。
- RGB函数以early SOF归零，仅在valid消费4像素推进；行/帧几何1280×720，不能把提前tuser当第一个有效像素。
- 使用`tests/run_edge_stability_diag.py`的`fixture(1280,720)`同一整数图：直边、弱边、斜纹、圆形及lane差异；增加固定坐标标尺时单独定义金标准，不能用会随帧号变化的图案。
- 不把图案插在OSD之后，否则无法检查算法；避免动态CNT污染一致性计算。
- 保留K3/K4语义，不新增按键复用；仅EDGE显示固定源，ORIGIN继续显示摄像头。诊断选择与接线范围在归档说明中标出，不能把整个AWB总线共同替换而改变ORIGIN语义。
- 首先RTL逐点匹配固定图并验证控制；再完整TD流程，不能使用原QUALITY的+0.009ns代替诊断bit自身STA。
- PROGRAM_SRAM，保留旧candidate；回退重新烧录原QUALITY bit，无Sensor参数更改。

### 判读

| 结果 | 下一步 |
|---|---|
| 固定Edge输入和控制合规，Edge末端逐帧相同，HDMI仍变 | 查打包字序/DDR读写身份/欠载/mixer及物理时序 |

## C. 只有B异常时：固定RGB + 独立合法时序

独立诊断配置产生320有效拍/行、720行、明确行间消隐与足够提前SOF间隔；仍保持外部HDMI720p、原PLL和SDC。
不得把它与B混为一次对照。合成前检查帧平均生产率与DDR吞吐，不能因任意加速生成器制造假欠载/溢出。

- B失败、C稳定：真实控制事件/时序形态是重点，不是证明RGB噪声。
- B/C均在Edge末端错误：查Edge状态或实现；末端正确而显示错误则下游优先。
- 该实验不能证明真实MIPI稳定，因为已绕过其控制。

## D. 当B稳定时：收敛AWB冻结与真实输入对照

1. 真实静物场景固定，先等待gain/count轨迹达到稳定；固定参数不调整。
2. 同一份诊断实现，分别记录连续更新与**保持当时已收敛R/B增益**的短序列，最好交替顺序，避免灯光温漂混淆。
3. 冻结开关只改变增益更新，不改样本选择、Sensor、阈值、滤波、位深或像素时序；帧边界原子执行，不将增益切回1×。
4. 同时采到前AWB RGB与后AWB RGB固定ROI，至少100个独立采集帧（带采集frame_id），记录gain/count、平均行亮度和各级变化。
5. 冻结后变化显著减少且前AWB相近、后AWB相关变化下降，才支持AWB贡献；冻结后仍有变化不能证明AWB完全无贡献。
6. 在稳定直流光源下重复，若行亮度周期相关显著减弱，才支持照明贡献；频谱峰须考虑真实Sensor帧率与混叠，不能拿HDMI60Hz替代采样率。
7. 区分少量RGB码值变化/梯度翻转与整帧坐标错位。独立模型重放实际捕获ROI时需包含卷积/四跳所需halo，统计只用中心区域。
