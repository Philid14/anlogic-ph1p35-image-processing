# EDGE_V1 candidate 上板测试

此版本固定 Edge 模式，比较基准为用户已选择的 GAIN_TEST_E（Original，15.75×）。所有 sensor/ISP 参数冻结。新Sobel在FPGA内运行；输出格式1280×720，水平边缘采样为640点，每个结果复制两像素，阈值为80（`|Gx|+|Gy|`口径）。本轮未增加运行时切换或MODE文字，现有安路Logo和CNT保留。

## 烧录与对照

1. 保持摄像头机位、场景、灯光、显示器设置相同；手机拍屏锁定曝光/白平衡。
2. 用 PROGRAM_SRAM 下载已归档 `artifacts/bitstreams/GAIN_TEST_E/camera_to_dsi_display.bit`，记录Original画面；不要按曝光/增益键。
3. 用 PROGRAM_SRAM 下载 `artifacts/bitstreams/EDGE_V1/camera_to_dsi_display.bit`，等待3–5秒。正常现象为黑底白色边缘，OSD文字/Logo仍是原有彩色。
4. 放置白纸与黑色物体形成强边界，分别观察竖直、水平、斜向直线；再观察室内物体轮廓、细线、文字笔画和缓慢移动物体。
5. 检查整幅是否保持720行，是否有错行、撕裂、周期性条纹、闪屏、输出中断；记录安路Logo、CNT和HDMI连续性。
6. 保持运行至少30分钟，再做明暗照明变化。记录高增益下噪点是否被显示为假边缘，以及画面/OSD是否连续。没有仪器统计时写观察结果，不填写虚构的零溢出数值。
7. 如有明显异常，使用已归档GAIN_TEST_E bit恢复Original，并反馈触发场景。需要修改阈值或算法时另立实验commit，不同时改曝光/AWB/BLC。

## 已知边界与判断

- 前两行及每行首4像素为黑色，是行窗口初始化/左边界屏蔽；不把它误判为整行丢失。
- 因果窗口中心在上一行和前一个水平采样点，显示相对对应边缘约右移2原像素、下移1行；细节精度低于完整1280列逐像素Sobel。横向两像素成对变化属于本候选定义。
- 高模拟增益可能让噪声形成大量小边缘；当前没有高斯/去斑点步骤。先记录现象，不能把阈值80描述为最佳值。
- RTL/模型已逐拍比较算法、打包及接口，TD全流程结果见BUILD_INFO；这些均不替代真实上板稳定性。
