## 1. 可学习的空台面参照

测量RUN、ORIGIN下，短按并松开K4，学习**空台面**完整一帧；CAL状态的K4仍用于厘米尺子标定。先做尺子标定，再移走尺子学习空背景，最后放工件。不是开机自动假设工作台为空。

工作ROI x256..1023、y160..543，每16×16格在中心行取4个间隔4像素的灰度样本平均，48×24=1152字节，用1个原生ERAM。为节省资源，最终不是整格256像素平均；因此要求空台面平滑、少纹理。推理仍逐个源像素计算有符号Y−背景参照，绝对差≥12为前景，兼顾亮、暗两种表面。3像素连续段/每行至少6个合格像素拒绝孤立噪声；亮暗两侧边缘可共同确定外廓。无学习参照时保留旧固定阈值/极性路径。

学习必须完整帧、行末几何一致、全部1152格写齐；失败不发布参照。复位、进入CAL、重新学习清除ready；帧中途的clear/request不改变当前帧的分割方式，只在SOF切换。学习期间不读取同一ERAM，避免读写冲突。统计分支增加2时钟，主视频数据及31时钟公共延迟不增加。

BG:NEED/WAIT/OK/FAIL和K4 EMPTY提示在测量图下方；AUTO12表示上一完整测量帧用了背景参照；CUT表示使用原阈值。BINARY画面仍是原固定阈值预览，不能把它当成AUTO12的掩码预览。K4在BINARY/EDGE依旧调阈值，不学习背景。

固定机位、同一工作平面、固定光照、单个分离工件。更换台面/机位/显著改变灯光后应清空并重新学习。阴影、背景纹理、AWB或光照变化可能产生假前景；16像素格内大纹理不适合。完全过曝或与背景没有可见差别的外边缘不能恢复；学到工件本身也不能正确测量。

## 2. 显式圆片D/R（最终方案，非自动圆弧拟合）

曾实现近圆面积/对称性判定，独立模型/RTL可区分测试圆片、方块、菱形和T形，但整机面积超限。源码检查点保留，最终正式实例明确SHAPE_ENABLE=0，自动分类/DSP不进器件。不能将该独立算法测试宣传为最终功能或实板识圆成功。

最终用原来无用途的**ORIGIN测量RUN下长按K4**，在W/H与D/R两种测量档之间切换，一次长按只切换一次，不响应重复事件。显示K4 HOLD: W/H或D/R，短按仍学习空背景，CAL与BINARY/EDGE按键语义不改。

操作者放入已知圆瓶盖后选择D/R，圆片上方显示D（水平外径），从中心向右边缘绘制半径线，右侧显示R=D/2。沿用同平面的粗略公共X/Y比例尺，单位MM，未标定时PX。恢复W/H档再测矩形/异形件。D/R是依据“完整正俯视圆片”假设的外径/半径，不是自动识圆，不支持任意局部圆弧拟合；不能把方块放在D/R档便声称识圆。GAPX/GAPY仍只是中心截线空隙，反光空洞不等于真实内孔。

## 3. 红色LAST跟随框

直接缓存TARGET既有完整结果中的44位bbox，与LAST中心、数量、帧号同次发布；状态OSD在同一个SOF锁定整组。TRACK绘制2像素绿色外框，取消原来的全目标绿色填充，保留红物体真实画面。无效、无目标、异常/取消结果不画框，原有guard防止过期结果成为新有效观察。

**框与LAST文字属于上一完整采集结果**，不是同一显示帧的逐像素定位：快速运动会有采集帧级滞后。没有增加DDR元数据或伪造同帧身份。若源暂停，DDR可能仍重复原图和旧框，原有HDMI SOURCE STALE告警负责提示，直到新源帧到来才重画；不能声称源停时已从DDR删除旧框。

X/Y为包围框中心，N为匹配像素数量，均为HEX；FRAME也是HEX。截图27F/167/028BB对应639/359/10427。左右运动改变X，上下改变Y，面积/距离/遮挡改变N，消失后VALID=0，FRAME随新采集更新；ERR为协议异常sticky，不是检测置信度。多个红物体会合成一个总框，不是多目标独立跟踪。

右上B/S也是HEX：B统计前600个采集帧中出现write-valid且FIFO-full事件的帧数，S统计之后的此类帧数，均饱和到FFFF；不是亮度/饱和度，也不是溢出像素总数。启动B非零不能直接认定稳态连续丢帧，S持续增长则需优先排查。SW为逻辑开关状态，R是读尺状态（R3为上次CAL成功），不是目标坐标；TRACK下THRESHOLD留空，K4不调红色检测阈值。

## 4. 资源收敛与冻结范围

首轮源码0463a95布局打包21727>21216，第二轮3da5e12为21529>21216，第三轮fe5d363为21651>21216，配置RAM版986c5db仍21367>21216，均未生成bit。保留失败证据。最终取消自动近圆分类，采用显式圆片档，继续精简由光栅坐标/finished/geometry已完全覆盖的冗余计数、用单有符号减法实现双极性差值；前景总数只需判断是否达到64，用饱和小计数代替宽计数，外廓坐标精度不降低。

最终配置/UI共23位，用同一CSI时钟下原生DP存储精确逐拍延迟（TD实际占2个ERAM20K），保留第0拍、空间算法末拍和公共末拍三个抽头。32地址环、25拍空间抽头和末端2拍，任意相邻SOF/随机配置逐拍对应，不依赖“下一帧不会太快”的假设。比尝试让TD自动推断移位存储更直接。active_config、ui_frame、valid/SOF/last及各状态机仍有复位；复位清除有效管线，首拍有效数据到达时RAM对应数据已完整替换，不增加像素延迟。不是异步FIFO，不新增时钟或CDC。

CSI两处字库改为同步原生ERAM，地址从既有字符寄存器前取，复用原两级渲染管线；4096种字符/行与旧字形逐一相等。每口1ERAM，字形外观不变。此优化不声称单独显著省面积，实际节省以整机布局报告为准。

正式Sensor/曝光1990/VTS1000/HTS1600/15.75×/BLC15/AWB、五种原算法、厘米尺子、颜色对比、MOTION、MIPI/DDR/HDMI、Logo/CNT、PLL/引脚/SDC不变。入口增加font/background/config delay/shape select模块。K3七模式顺序不变；扩展原来无作用的ORIGIN测量RUN下K4：短按空台面学习，长按W/H-D/R选择。

历史FIFO sticky/Gray约束覆盖和高密度/温度/长期稳定风险保留；仿真和STA不等于实板通过。
