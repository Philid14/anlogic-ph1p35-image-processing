## 对照矩阵

每个bit都扫描20/40/60/80/100/120/160，不以同一默认080定优劣。80→60/40/20每步短按两次；上调每次长按加10，确认OSD后再操作。另检010/250钳位与数字100/200/250。固定阈值先观察，再扫描各自最佳噪声/轮廓折中。

1. **弱光暗色物体**：最重要。固定目标轮廓附近和无物体平坦背景各选相同ROI；分别记录真实轮廓长度/最长断口、平坦白点数量或比例、大片白噪声、小细节和推荐阈值。没有导出帧能力时拍屏并明确“主观观察”，不虚构精确误检率。
2. **正常室内**：白纸/文字、横竖/斜边、细线；记录笔画、细线是否消失以及强边缘是否仍清楚。黑背景增加不能单独证明效果改善。
3. **全遮光/局部遮挡**：先看明亮场景再遮挡，检查没有上一帧残留、异常整行/整列伪影；比较局部遮挡的白点。至少重复3次。
4. **移动物体**：横向/纵向移动同一目标，观察连续性、核偏移、行间拖尾、错行和撕裂。新增算法是空间滤波，不含时间平均，不应引入跨帧运动拖影。
5. **控制和长稳**：至少20次ORIGIN↔EDGE；ORIGIN模式调阈值应只变文字、不改变彩色主体。连续运行至少30分钟，期间明暗变化及反复调节，记录Logo/CNT、OSD状态、HDMI断连、周期花屏/缓存异常。无测量计数时不写“零溢出”。

## 已知边界

Gaussian+Sobel因果核中心约比输出位置左4原像素、上2行；首4行及每行首8原像素黑。旧版约左2像素/上1行，比较ROI需补偿该已定义差异；不是整帧错位。两版都只有640点水平边缘采样、结果复制两像素。Gaussian会降低部分细线/弱梯度，最佳阈值可能低于旧版；过低仍会放大噪声。合成模型结果不能替代此实拍。
