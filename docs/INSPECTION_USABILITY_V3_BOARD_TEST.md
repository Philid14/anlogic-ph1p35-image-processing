# INSPECTION_USABILITY_V3 上板步骤与开关核对

本版用于修正V2实板读尺失败、色块框太大，并取得可靠的物理开关映射。先用本版归档bit，
不要沿用旧Runs文件。出现右上`SW:xxxx R:n`且颜色框明显缩小，才是本版界面。
原五模式、Sensor/ISP参数、K3/K4和物理引脚不变。真实识别成功率与尺寸误差尚待验收。

## 一、先核对实际开关

**本轮用户最终确认按从左到右编号，不按丝印编号。** 先前基于界面推断的物理路数表不作为接线结论。

诊断行示例：`SW:0101 R:0 MA`。SW的四位从左到右依次是**逻辑位0、1、2、3**，
是同步/消抖并随采集帧锁存的输入，不是实板开关排列。

| SW中的位次 | 引脚 / 功能（电平1时） |
|---|---|
| 第1位，逻辑0 | A4，颜色框及颜色参数显示请求 |
| 第2位，逻辑1 | B4，尺寸界面请求，优先于颜色 |
| 第3位，逻辑2 | E11，BRIGHT；0为DARK，仅RUN测量时使用 |
| 第4位，逻辑3 | D11，尺寸CAL请求；0为RUN；实际读尺还要求ORIGIN |

末尾M=尺寸，C=颜色，-=两者都关，A=尺寸CAL请求。
例如SW:1000为颜色，SW:0100为尺寸RUN/DARK，SW:0101为尺寸CAL，SW:0110为尺寸RUN/BRIGHT。
SW:1100同时请求两功能时显示尺寸，所以某一路切到0后“露出颜色”未必说明它是颜色开关。

1. 固定其余开关，记录基准SW四位。
2. 从左到右，单独拨第1路，记录变化后的SW，恢复；对第2/3/4路重复。
3. 以哪一位实际翻转认定作用和方向。请反馈“基准xxxx；左1→xxxx；左2→xxxx；左3→xxxx；左4→xxxx”。
4. 若某一路拨动后SW完全不变，先核对板卡型号/开关区域与原理图，不能据画面断言开关坏或随意换引脚。

## 二、颜色比对

两框内实际采样均为32×32，相比V2的128×128面积缩小到1/16；中心位置保持不变。
REF x304..335、y304..335；TEST x944..975、y304..335，分别在画面左/右的原中心。
按上表使颜色逻辑位1、尺寸位0。移动色卡，使框的内部完全位于单个色块，不能包含黑色隔线。
颜色统计仍取算法前RGB，不受GRAY/EDGE/STYLE渲染影响；建议用ORIGIN观察放置。
类别仍是粗颜色标签，不是标准色度校准或ΔE。检查缩小后数值是否更符合单块，记录静止10次读数和光照。

## 三、读尺与测量

1. K3到ORIGIN；根据SW诊断，使尺寸位1、CAL位1（例如SW:0101或1101）。极性位不影响读尺。
2. **先用无字的哑光白纸作背景。** 用户照片中透明尺下的密集文字和蓝点可能干扰采样，先排除这项因素。
3. 将有1mm短刻线的直边水平放入框，刻线朝向相机，尽量正对、清晰且无高光。
   新版在框内采十二个高度，不必再手动调整SPAN；仍要求短刻线在图像上可分辨。
4. 短按松开K4一次。R1等待下一完整帧，R2分析，R3成功；看到CAL OK后再移尺和退出CAL。
5. 第4逻辑位设0进入RUN，比例保留；深色片白底设第3逻辑位0=DARK，浅色片黑底设1=BRIGHT。
6. 单个薄工件居中平放、边沿与画面轴平行。K3到BINARY、RUN中用K4短按-10/长按+10调好分割，再回ORIGIN。
7. W/H仍是整体外包宽高，X/Y为固定中心孔槽截线，不是自动圆拟合/所有CAD特征。移走工件应清除旧尺寸。
8. 用另一段已知真实长度分别横、竖复核；本版仍X/Y共用比例，必须正俯视、同工作平面。
   记录10次尺寸、误差和极差、旋转90度W/H交换、不同位置及30分钟稳定性；小数位不是精度承诺。

## 四、按R码区分失败

| R码 | 意义与下一步 |
|---|---|
| 0 | 尚未标定；确认MODE ORIGIN、尺寸/CAL启用，再短按K4 |
| 1 | 等完整帧；确认摄像头画面持续更新 |
| 2 | 正在分析 |
| 3 | 比例已获得，仍须独立已知长度检验 |
| 4 | 采样线对比不足；检查刻线是否入框、焦点、反光及光照 |
| 5 | 无可信周期/覆盖不足/可读线比例不一致；检查1mm短刻线、背景文字、斜放与清晰度 |
| 6 | 视频帧几何错误；**停止按尺子图案问题处理**，记录B/S、SW和是否持续复发，优先定位视频完整性 |
| 7 | 采样时离开CAL/ORIGIN等导致取消；保持状态重新按K4 |

算法仍不能由周期证明单位。如果只采到厘米长线/规则背景也可能误判；必须让1mm短刻线入框并检查已知长度。
如果仍FAIL，请提供R码和完整界面；一张新照片即可先区分故障类别，不要求重新录101页数据。
标定不保存到Flash，复位/重烧录后重新读尺。验证稳定后再考虑PROGRAM_FLASH；历史bit/tag全部可回退。

Board Test Status：NOT_RUN。原FIFO B/S与Gray覆盖风险未修复，S若稳态增长，先处理视频流可靠性。
