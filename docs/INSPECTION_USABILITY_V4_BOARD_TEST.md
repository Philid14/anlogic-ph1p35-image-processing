# INSPECTION_USABILITY_V4 上板验收 / MAIN

仅使用本版本归档bit，先PROGRAM_SRAM。板卡测试尚未执行；不将仿真视作实板结果。
右上仍有SW四位和R码；颜色第五行出现CHR/DV/CLIM，CAL框明显扩大才是V4。
物理开关仍按用户从左到右编号，实际对应关系由SW变化确定，不按丝印或旧猜测套用。

## 开关与按键

SW显示顺序为逻辑0→3，不是物理排列：0颜色、1尺寸优先、2明暗极性、3CAL。
1000=颜色，0101=尺寸CAL，0100=尺寸RUN/DARK，0110=尺寸RUN/BRIGHT。
K3仍切五模式；正常BINARY/EDGE下K4短按-10、长按+10；ORIGIN/尺寸CAL下短按K4开始读尺。
不要在搜索途中反复按K4，新的请求会撤销旧比例并从头开始。

## CAL大框验收

1. 固定俯视相机、焦点、工作平面、灯光。无字哑光白纸作背景；不要在透明尺下放印刷字/规则点阵。
2. K3到ORIGIN、SW调0101。实际搜索x256..1023/y192..479，768×288；框线与采样边界一致。
3. 将清晰的黑色1mm短刻度边**水平**放入框中任意高度，不必对准某条扫描线。
   要求刻线至少跨两相邻像素行，框内有≥24可信间隔、累计≥128px覆盖；不是尺柄入框即可。
   2..16px/mm为当前可识别尺度，过小、模糊、斜放、反光、只有厘米长线不能保证成功。
4. 短按松开K4一次，保持不动直到终态。R1等待下一完整帧，R2逐带搜索，R3/CAL OK成功。
   最多27带，约54个源帧周期加分析/等待；可能需要数秒。不会占用整帧缓存，也不冻结视频。
5. 分别把刻度移到框上、中、下及左右位置，重复采样，记录R码、独立尺寸和是否需要重试。
6. 成功后移走尺子、SW调0100，放薄深色矩形配白底，边沿与画面轴平行；已标定比例保留。
7. 独立用尺量长宽，比较工程尺寸线W/H；静止10次、旋转90度、不同位置、移走清除。
   X/Y仍共用比例，俯视/同平面是前提。不要把显示小数位当计量精度；复位后重新标定。

R4=搜索完毕无足够对比；R5=搜索完毕无可信刻度/两线不一致；R6=视频几何异常，优先记录B/S及复发；
R7=退出CAL/ORIGIN等取消。失败保留完整界面照片；不要通过改Sensor/阈值强制通过。
读尺用自己的逐行阈值，与BINARY工件分割阈值是两件事。

## 两侧同物体颜色验收

1. SW调1000、ORIGIN。两小框仍32×32，完整放进同一张均匀哑光色纸，不含边缘、黑隔线、阴影和反光。
2. 原REF/TEST RGB、ABS/L1/MAX及RAW LIM012保留原义，差值不会人为归零。
3. 新CHR为255刻度的RGB占比最大差，CLIM006；DV为RGB最大分量差。两者不是ΔE、照度或标准色差。
4. MATCH=可靠数据且原RGB MAX≤12；LIGHT=原RGB不同但占比接近；DIFF=占比明显不同；
   CHECK=过暗/接近截顶，归一化判断不可靠，CHR显示---。
5. 同一张色纸在固定灯光下分别测中心/左右，记录RGB、CHR、DV、状态各10次；左右交换两件同色哑光样本再测。
   等比例明暗差预期更容易显示LIGHT，但不能保证真实照明变化严格等比例。
6. 换明显异色样本应DIFF；换同色不同深浅样本可能LIGHT，不能作为合格品判据。
   极暗与高光样本应提示CHECK，避免将归一化的低可信数据当匹配。
7. 在安全、不移动相机和样本的条件下，用纸遮挡部分灯光或改变一侧补光，观察RGB/DV与CHR是否分开反应。
   手/遮光纸不要进入采样框，不要用屏幕反光当摄像头照明证据。

LIGHT只提示“占比接近而明暗不同”，无法区分照明差与材料反射率差；不自动判MATCH。
若同物体CHR也明显不同，应复核两侧光源色温、表面反光、镜头/ISP空间响应；本轮没有平场色度校准或Sensor/AWB调整。
当前仍需均匀、漫射、固定光源才能作可靠物料颜色对比。类别C仍是粗标签，不是标准色卡绝对RGB认证。

## 系统回归与回滚

切换五模式、颜色/尺寸/CAL，Logo/CNT及原阈值语义应保留，关闭两应用后框和应用参数消失。
检查移动/移走尺寸标注、模式切换、正常明暗变化及30分钟无花屏；记录B/S在启动后5/30/120秒及终点是否增长。
S稳态增长或R6复发为验收阻断，先处理视频完整性。既有Gray指针约束风险未排除。
回滚重烧INSPECTION_USABILITY_V3归档bit/tag；历史版本不覆盖。完成测试后反馈，不继续下一版。
