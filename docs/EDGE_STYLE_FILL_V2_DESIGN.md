## 候选比较与选择

独立模型比较V1、8级RGB+旧描边、共享明度+旧描边、最终V2。
8级通道量化缩小台阶，仍会在各通道跨阈值时产生彩斑，也不修复亮细线侵蚀。
只换共享明度能修复色差放大，但旧描边仍吞亮线。因此选择一套协调的STYLE渲染策略：
**保守局部均值 + 共享明度分级/低色度中性保护 + 一致亮度梯度的暗侧描边**。
没有额外高斯、中值、帧历史或全图模糊。

## 精确算法

坐标窗口`a=左上,b=上,c=左,d=当前`；首行/列没有完整邻域时只执行调色板。

1. 仅当四点RGB各通道的高4位完全相同时，使用四点四舍五入均值；否则保留当前RGB。
   比V1跨度≤2的均值资格更保守，避免混合小字/低对比细节。
2. 原始邻域亮度 `Y=(R>>2)+(G>>1)+(B>>2)`，范围0..253，不复用旧Edge的640点采样。
   `Dx=abs((Yb+Yd)-(Ya+Yc))`，`Dy=abs((Yc+Yd)-(Ya+Yb))`。
   仅`max(Dx,Dy)>=96`且`4*Yd<=Ya+Yb+Yc+Yd`时描黑。
   相当于两侧均值差≥48，并限定当前点在暗侧；棋盘式相消纹理不强制变黑，亮细线不被暗邻域覆盖。
3. 取步骤1基色的`lo=min(R,G,B), hi=max(R,G,B)`，明度`L=(lo+hi+1)>>1`。
   `Q(L)=255 if L>=240 else 32*floor((L+16)/32)`，形成9个明度档。
4. `hi-lo<=12`时输出`(Q,Q,Q)`，抑制低色度区域杂色；否则输出每通道
   `clamp(C+Q-L,0,255)`。共享偏移保留未截断通道差，不逐通道扩大色差。
5. 描边覆盖步骤4为黑。没有时间历史、递归连接、扫描线内外翻转。

偏移在−15..+16间，有符号位宽/截断必须逐值验证；过饱和彩色通道可能夹断。
浅淡彩色（色度≤12）会去饱和，这是中性色保护的已知代价，不能称为自动白平衡。
等亮度纯色边界可能不描黑，但色块边界保留；低对比边界不保证描线。
9档明度仍有色带/门限闪烁，未承诺时间稳定性或修复实际过曝。
