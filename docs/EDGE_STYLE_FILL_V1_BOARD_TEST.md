## 操作

1. 保持原机位/灯光、摄像头、HDMI与供电，重新PROGRAM_SRAM，记录版本、bit SHA、时间。
2. 复位默认EDGE/080，K3依次为 ORIGIN、GRAY、BINARY、STYLE、EDGE。
3. STYLE显示 `MODE: STYLE`，阈值数字留空。K4在STYLE忽略；仅EDGE/BINARY支持短减10、长加10，两个值独立保存。
4. 先在ORIGIN确认物体本身清晰，再依次对比 BINARY、STYLE、EDGE；不要把不同模式当作同一种处理的优劣排名。

## 最小且有判别力的场景

| 场景 | 正常效果 | 已知限制 | 失败判定 |
|---|---|---|---|
| 白纸上黑色实心矩形、圆，另加空心轮廓 | 黑白形状内部保持黑/白，强边界描黑，背景不大面积反转 | 不把空心图形内部灌成另一种颜色；白纸仍白 | 缺口导致整行变色、整片背景填满 |
| 红绿蓝不同日常物体 | 内部出现粗调色板色块，边界黑线，区别于BINARY | 同一物体可能有多种色块；没有对象身份 | 只剩二值黑白、通道/像素排列错乱 |
| 纸边或轮廓留小缺口、开放线 | 缺口影响局部，线外背景不传播改变 | 不保证闭合/补洞 | 改变一小口后远处大范围翻色 |
| 两个独立目标、相邻/嵌套图形 | 各自局部填色，强色差边界可见 | 两个同色接触物体无法区分；间距1px可能被黑边占据 | 无关远处对象随另一对象整体变化 |
| 触及图像边缘 | 首行/列安全退化为原色块化，不出现旧帧条带 | 画框最外一行/列没有完整2×2边界检测 | 首行/列出现上一帧内容、行位移 |
| 小字/细线/小物体 | 应无数据错位 | ≤1px细节可能变黑/消失，属于本方案限制 | 大物体也出现4px周期破碎/行错位 |
| 缓慢平移纸张、手掌 | 当前帧色块跟随，不出现跨帧拖尾 | 调色板门限仍可闪烁，边界右/下最多1px加粗 | 物体移走后仍有多帧色块残留 |
| 快速进入/移出、遮挡镜头 | 当帧更新，恢复后无旧行污染 | 实际显示存在原DDR延迟 | 新模式独有残影或持久条带 |
| 暗部/渐变/纹理 | 适度简化纹理，明显色阶可预期 | 高增益噪声可能描黑；非降噪/时间稳定版本 | 随机花屏、画面卡顿、无法回原图 |
| 五模式反复切换/K4 | OSD和整帧模式对应；阈值保存；回EDGE历史正常 | 按键到下一采集帧才生效 | 同帧上下模式混杂、EDGE历史断更、阈值丢失 |

历史sticky/Gray max-delay约束覆盖缺口未在本轮修复。
**S持续增长、花屏、错误打包/行位移均阻断正式验收**，应保存触发场景并回滚对照，
不得把这些异常解释成STYLE正常画质。

必须轮换检查原图、灰度、二值、EDGE各自正常，安路Logo/CNT可见；光照变化后仍连续。
记录手机曝光/白平衡，比较时锁定，避免手机自动曝光掩盖调色板效果。
