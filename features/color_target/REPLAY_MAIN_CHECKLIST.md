# 给 MAIN 的回放交接清单（待确认，未代发）

当前仍为 TARGET 独立实验；相机素材、最小目标与同色策略按用户要求保留。
不改主工程、时钟、DDR、sensor、共享 OSD 或 TD 主入口。

| MAIN 需确认/提供 | TARGET 已准备的依据与检查 |
|---|---|
| 规范化彩色观察点及 lane 顺序 | RGB 文件回放与原检测器健康帧旁路对照；默认 lane0=[95:72] |
| SOF/EOL/EOF、原图坐标、帧内稳定身份 | 新统计器拒绝错误完整帧；EOL 不能替代 EOF |
| abort、掉拍、截断后的恢复动作 | 已验证空闲拍 abort；截断须显式复位，复位会取消全部未发布结果 |
| 是否允许复位取消上一帧在途结果 | 工具逐帧记录取消；若不能接受，需要另定恢复设计，不能假定已有缓存 |
| 结果身份与显示帧关联、显示帧边界锁存 | 回放只在稳定后查显示端口；未实现 DDR 元数据和显示适配 |
| 观察域到显示域整组 CDC | 仍需原子握手/适当 FIFO；单个脉冲或字段分别过两级同步不足够 |
| 标注区域、优先级和共享字库 | 使用现有独立覆盖接口；不得遮挡安路 Logo；本轮字形像素用测试桩 |
| 资源与实际时钟预算 | 独立 TD 报告含测试架；真实 route setup/hold 与整机增量尚待主工程确认 |
| 相机 RGB 素材和采集配置 | PPM/manifest 模板、哈希、标注校验及逐帧评价工具已备；未取得实际素材 |

推荐先保持过滤关闭接入稳定基线，逐项确认身份、错误帧处理和显示，再考虑过滤的实际收益。
