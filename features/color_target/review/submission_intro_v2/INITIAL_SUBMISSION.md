作品名称：基于安路FPGA的实时图像处理与颜色目标检测系统

作品简介：本作品基于安路PH1P35 FPGA和HX1P35A开发板，拟实现MIPI视频采集、数据解码与缓存、硬件图像处理及HDMI连续显示。采用SC500CS摄像头，结合厂商接口IP与参考工程完成RAW10解包和拜耳图像转RGB，HDMI输出目标为1280×720、60Hz。使用Verilog实现灰度转换、二值化和Sobel边缘检测，通过拨码开关切换原图与处理模式，通过按键调整阈值。针对可控场景中的单一红色或蓝色目标，采用YCbCr颜色阈值分割，结合像素计数和坐标极值统计确定目标范围，利用上一帧检测结果在当前画面绘制包围框。通过OSD显示模式、阈值、帧计数和检测状态。系统采用定点运算、硬件流水线和行缓存，结合视频缓冲管理、跨时钟域处理及同步信号延迟匹配，兼顾实时性与资源占用。使用固定测试图比对算法结果，测试模式切换、长时间运行及光照变化下的显示稳定性和检测效果，检查花屏、错位、缓存溢出与欠读，并记录资源占用、时序裕量和处理延迟。
