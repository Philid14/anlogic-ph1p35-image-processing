# 实测现象如何提升简介——请主控重点说明

本文件为测量建议和审阅要求，尚无实测结果。未给定的样本量、测试时长、通过准则由MAIN确认；下述建议不是比赛统一阈值，不授权修改生产颜色/尺寸阈值。

每项需形成：**输入/条件 → 观察现象 → 原始记录/指标 → 能支持的表述及限制**。请使用独立重新摆放的样本统计，不把同一次放置的连续视频帧伪装成大量独立试验。

## P0：版本与实际操作先绑定

记录实际下载文件、SHA256、源码/标签、板卡和摄像头、显示器/线材、供电、镜头高度/焦距/工作平面、光源位置和模式/阈值。实际下载版本未核对时，注明“版本未核对”，不能将现象直接归到当前候选。

拍摄一段能同时说明实物和显示器的录像：原图、GRAY/BINARY/EDGE/STYLE、Logo/阈值/状态；颜色与尺寸界面分别切换，核对拨码真实功能及板上丝印。旧文档的SW0逻辑序号不直接等于实板从左数的第一路。

**文案价值：**让“系统已实现”有版本绑定的实物证据；能说明五模式如何服务观察与检测，便于主控确认简介中的交互描述。不能由录像代替帧率、精度和长稳测量。

## P0：同材/异材、交换位置与颜色重复性

**输入与步骤：**固定光照/相机；参考和待测材料完整覆盖各自128×128取样区。先将同一材料的两个样本分置两框，再换为不同材料/颜色；分别交换左右位置，多次独立重新放置。至少包含肉眼接近但存在差异的样本，以及易反光或出现高光的情况。保持既有LIM12规则，不为了获得好结果修改阈值。

**观察：**记录REF/TEST RGB均值、ABS/L1/MAX、粗颜色名、MATCH/DIFF和LAST；同材是否随位置翻转、相近色是否出现误判、RGB是否贴近0/255、值是否长时漂移、改变显示模式是否伴随系统性变化。相同粗色名并不等于RGB差小，不能把“两个都RED但DIFF”自动当成故障。

**记录与指标：**明确“同材/异材”真值来源；以每次独立放置后的稳态读数为样本，给出样本数、重复试验结果、差值范围、同材被判DIFF和异材被判MATCH的次数。若只人工抄取几次读数，就报告这些读数，不声称逐帧识别率。

**逻辑解释：**同材交换位置后差值明显变化，提示照明不均、镜头/ISP位置依赖等影响；反光或RGB剪裁会让颜色信息失真。当前指标是相机RGB码值差，不能当CIE Lab/ΔE、材质鉴别或印刷标称色度。

**可提高的简介表述：**当前“显示RGB均值与通道差异”是功能事实；若数据支持，可写“在[具体照明/样本条件]下，对[N次独立放置]的颜色差异进行重复观察/比对”。先给原始结果，再决定是否有足够依据写辨别能力。只会显示数值时，不能升级成高准确率颜色检测。

**请MAIN说明：**为什么选择这些材料/位置；怎样区分真实颜色差异和光照/反光影响；哪组现象最适合现场展示；可写入简介的短句及仍需保留的条件。

## P0：两轴真实标定与尺寸误差

**输入与步骤：**固定相机、焦距、高度和同一工作平面，用100mm标尺段分别完成X/Y对齐与确认；拍下刻度与屏幕标定端点。先测平放、轴对齐、背景对比明确的单薄件，再换尺寸和画面位置，多次独立重新放置。使用已有可靠量具/已知尺寸获得W/H真值，注明量具分辨率和参考不确定度；没有可靠真值则尺寸误差仍填未测。

**观察：**未标定显示PX，操作确认后切MM；CAL:OK只表示操作流程，不证明标尺对齐正确。观察数值跳动、轮廓断裂、阴影/高光、背景误分割、画面边缘与中心偏差。旋转工件使轴对齐外包增大属于已知几何边界，不能直接解释为标定坏了。

**记录与指标：**每次记录工件真值、位置、方向、标定像素跨度、阈值、W/H读数。误差=读数−真值，分别给偏差、平均绝对误差、最大绝对误差和重复摆放范围；数据不足不写全量程精度。建议每组合至少5次独立重新摆放供初步观察，最终样本量与演示允差由MAIN确认。

**间隙另测：**GAPX/GAPY是固定十字线的背景截线；把已知槽/开口对准十字线，再偏离中心观察变化。没有自动寻孔和圆拟合，孔不居中时不能把截线直接称真实内径。

**逻辑解释：**两轴分别标定可建立各自像素/毫米比例；位置、镜头畸变、对齐、标尺误差和工件高度仍会影响实际结果。显示0.1mm、初值256px和CAL:OK均不提供0.1mm准确度证明。

**可提高的简介表述：**从“支持标定后毫米显示”提升到“在[工件/量程/位置/照明]条件、[N次测量]中最大绝对偏差为[实测值]mm”等限定结论。只有足够实测才填写数字，禁止先选漂亮精度再补数据。

**请MAIN说明：**有效测量范围与误差来源；为何可/不可加入量化指标；该指标改善应用价值和可信度的方式；如果误差较大，应该怎样收窄场景或调整文案，而非隐去失败值。

## P0：长时间显示、移动验证与缓存状态

**输入与步骤：**记录真实持续时长；期间交替静态工件、手/工件移动、五模式切换和颜色/尺寸显隐。可先做短轮排障再做较长轮，项目验收时长由MAIN事先确认；赛题没有在此规定统一分钟数。

**观察：**花屏、横线、撕裂、图像/框/文字错位、瞬时黑屏、HDMI重锁、冻结/回跳、切换后无响应；让物体移动以确认主体画面持续更新，不能只看OSD计数在增加。每个异常记时间、模式、触发动作、次数、是否自行恢复、是否需要复位或重新下载。

**缓存指标：**请MAIN先解释B/S的事件定义、位宽、清零、回绕/饱和以及与实际FIFO的关系，再记录起止/增量。未知语义的零值不能证明零溢出、无欠读或不丢帧；无可信观测能力的指标填未测。若发现增长或视频异常，先暂停尺寸精度验收并分析链路完整性。

**可提高的简介表述：**有记录后，可用“在[条件]下连续运行[实际时长]，期间[切换次数]，未观察到[明确异常]”。如要写无缓存溢出/欠读，必须有对应计数定义、覆盖范围和可信记录。一次短视频不能支持长期稳定或零丢帧。

**请MAIN说明：**稳定性证据对赛题基础门槛和现场展示的意义；记录覆盖哪些故障，未覆盖什么；可写哪句、有何边界。归档STA通过不能代替这项实测。

## P1：明暗变化、饱和与恢复

**输入与步骤：**固定样本与相机，用已有可调灯或遮光改变亮度；记录基准、明显变暗、明显变亮及恢复原光照四段，并分别记录实际档位/位置等条件。没有照度计时不填写虚构lux。

**观察：**视频是否继续更新，有无黑屏/冻结；RGB剪裁、颜色判定翻转、轮廓/尺寸波动或无效提示；恢复原光照后是否自行恢复，实际耗时，是否必须手调阈值或重启。图像仍能输出与颜色/尺寸保持有效是两个独立结论。

**逻辑解释：**当前候选集成参考AWB，AE请求关闭，不能把画面恢复称作已实现自动曝光。光照变化下测量失效可能来自分割或颜色输入变化，也可能是视频链路问题，应分别记录。

**可提高的简介表述：**可报告已验证照明范围或“光照变化下保持视频输出”等具体行为；只有对应数据支持，才描述颜色/测量适应能力，不笼统写强抗光照。

**请MAIN说明：**哪些条件属于展示工作范围，哪些会使检测失效；恢复机制实际是什么；应如何限定简介中的应用场景。

## P1：显示模式与测量输入关系

保持样本、光源、阈值和标定不变，切换五模式，分别记录颜色/尺寸读数与状态。比较模式切换前后是否存在超过自然抖动的系统性变化；记录透明文字、采样框、测量框与对应参数是否在同一显示更新中一致出现/隐藏。

源码已证明统计并接在风格化前，实拍再说明切换交互效果。真实相机噪声/AWB会让不同采样帧变化，不能要求跨时刻数值逐位完全相同；一帧年龄与DDR延迟也不能伪称严格同帧跟踪。颜色与尺寸面板按应用选择，不把互斥界面写成同时展示。

**文案价值：**支持“切换显示模式保持取样来源一致”“处理效果与检测数据分路”等有具体结构依据的工程特点；若有明显系统性变化，主控应先查配置/阈值/取样路径，再决定是否保留该句。

## P1：无目标、触边与无效结果

先空置工作区，再将单薄件完整放入、部分移出ROI、移走、重新放入；核对空区/过小/触边时的无效提示、重新有效的时机、是否残留旧数值，视频是否持续。固定截线未穿过开口时，间隙读数不作为孔径真值。

实板可观察这些场景；错误EOL、缺失EOF等协议故障由已有独立测试证据说明，不把未实施的实板注入写成通过。结果来自前一完整采样帧，先明确正常年龄再判定旧结果残留。

**文案价值：**使“异常帧不阻断视频、无效结果有提示”有分层证据：协议异常靠模型/仿真，实际空区/触边恢复靠实板。不要把两者混成全部异常实板验证。

## P2：帧率与处理延迟

**先明确口径：**传感器完整采集FPS、HDMI刷新率、独立画面更新率（含重复/跳帧）分别记录。由MAIN解释现有CNT/LAST所数的事件，不能凭名义720p60、4PPC或显示器信息填写实测采集60fps。

**内部延迟：**口径为MIPI解码后某帧首有效像素到该帧HDMI实际首有效像素；需要同帧身份与共同参考时基。当前候选未完成可信LATENCY集成，不能用两个帧计数相减、VSYNC间隔或31拍局部对齐代替。

**若采用外部录像：**如用闪光/事件与屏幕同步拍摄，应注明它估计的是场景到显示响应，含相机曝光、传输和显示器响应；列出录像帧率/时间分辨率及不确定度，不能冒充内部计时结果。

**文案价值：**有效数据可把“支持720p视频格式/采用4PPC”补充成清楚的实测帧率或限定边界延迟。没有工具或身份关联时明确未测，保留结构事实即可。

**请MAIN说明：**当前有什么可用测量方法、各自起止边界和误差；哪些数值足以写入简介，哪些只适合技术报告。
