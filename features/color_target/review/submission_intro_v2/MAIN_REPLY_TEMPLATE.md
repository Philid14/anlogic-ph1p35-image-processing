## 数据充分后才可使用的措辞模板

方括号均为待填，不能当作已有成绩。优先选一两项替换469字符正文中较次要的接口/验证细节，保持≤500字符。

- 标定：“在[尺/位置/光照]条件下，[N次独立操作]成功[M次]，耗时[实测范围]。”同时给负例误成功，不只挑最好位置。
- 尺寸：“在[工件/量程/位置/标定]的[N次]测量中，最大绝对偏差[实测值]mm。”必须有可信真值和不确定度，不用0.1mm显示分辨率代替。
- 颜色：“在[材料/照明]试验中，[实际状态分布/重复结果]。”若不能确定差异来源，保留“疑似明暗/输入可靠性提示”，不写光照补偿、标准色差或材料合格率。
- 稳定：“在[条件]下连续运行[真实时长]，经历[次数]切换，未观察到[明确定义的异常]。”缓存结论另需信号定义与可信记录。
