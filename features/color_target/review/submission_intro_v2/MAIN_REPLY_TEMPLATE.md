## 基于证据的改写方式

以下带方括号的句子是条件模板，不是项目结果；不可原样当成绩提交。

- 颜色：“在[光源/材料条件]下，对[N次独立放置]的[样本]完成比对，记录到[实际结果]。”没有稳定判别数据时保留“RGB数值参照与粗分类”。
- 尺寸：“经[标定条件]标定，在[样本/位置范围]的[N次测量]中，最大绝对偏差为[实测值]mm。”给出参考真值与测量不确定度；显示分辨率不写成精度。
- 稳定：“在[实际条件]下连续运行[实测时长]，经历[切换次数]，未观察到[定义清楚的异常]。”缓存结论另需可信计数及覆盖说明。
- 帧率/延迟：“按[明确事件边界和工具]测得[值/范围]，测量分辨率为[值]。”无法区分采集与刷新，或无法关联同帧时不填内部延迟。

请解释最终选哪一两项写进500字符简介：它们如何体现实际用途、重复性、系统稳定或实时性，哪些详细数据应留在技术报告。不要把所有指标堆进简介。
