# 桌面一体式俯视暗箱框架 — FRAME_CONCEPT_V1

用途：为 PH1P35 系列开发板 + SC500CS MIPI 摄像头 + HDMI 显示器提供颜色对比、简单平面尺寸测量和后续 AE/AWB 实验的机械载体。此交付是可修改的空间布局模型，不代表颜色算法、测量算法、AE/AWB 或整机已实现。

**推荐方案 A：四柱暗箱 + 可换载板 + 外置电子设备区。所有默认硬件尺寸均为假设值，实测后才可出加工图。**

## 1. 总体结构与选型理由

操作人员站在前方（Y 负方向），相机垂直俯视中央载板；两条漫射灯沿前后方向布置于左右两侧。开发板位于暗箱右侧、接近相机高度，显示器位于右后方并朝向操作人员。二者均在遮光布之外。前帘可以上卷或打开，载板从前方取放。

| 模块 | 位置与做法 | 这样布置的原因 |
|---|---|---|
| 底座/工作台 | 暗箱和右侧设备区共用 18 mm 板材底座；6 个支脚；中央平面放置 360×240×3 mm 可换载板 | 桌面一体搬运；设备区有落地支撑；两种实验可共享参考面 |
| 立柱和横梁 | 600×500×720 mm 四柱框架；2020 型材包络；后侧 X 支撑及侧面斜撑；底部锚固 | 减少相机晃动，前面保留取放开口；不是经过计算的承载保证 |
| 相机 | 顶部双横梁 + 前后方向滑梁 + 竖直滑柱 + 可锁紧托板；镜头朝下 | X/Y 初调居中，Z 初调对焦和视场后锁定；更换载板不动相机 |
| 显示器 | 右后方独立立柱，固定到底座；正面朝前；背部预留假设 VESA 板 | 不把屏幕重量挂到相机横梁；操作时能侧看屏幕；避免屏幕光进入暗箱 |
| 开发板 | 暗箱右侧外部可拆托盘，随镜头高度参数近似联动；上方敞开 | 尽量缩短 MIPI 路径；散热、按键和下载口可接近；插拔时扶住托盘 |
| 光源 | 左右各一条带漫射面的条形灯；两端转轴、型材滑动锁紧；分别调光 | 对称照明便于同场比较；高度/倾角可改变；单侧灯可用于阴影/侧光实验 |
| 遮光 | 顶、背、左右固定布；前面重叠双帘；右侧穿线口用双层错位软挡片 | 尽量减小室内光和显示器漏光；前帘仍能快速打开；穿线处不直通漏光 |
| 维护 | 帘布快拆、前取载板、托盘可拆、灯具可单独移位；外侧走线槽及接头操作区 | 不必拆相机就能换样品/治具或调试板卡 |

底座默认占桌面积 **1040×600 mm**。框架高度 720 mm 从固定台面 Z=0 起算；支脚 30 mm、底板 18 mm、顶部布面到 Z=726，概念总高约 **774 mm**。需要另留操作、通风及线缆空间。若桌面太窄，可以把显示器用自带底座放到旁桌，删去模型中的显示支架；先确认相机视场，再缩小暗箱。

## 2. 两类场景与可换载板

### 颜色对比载板（scene="color"）

假设目标视场为 320×180 mm；标准卡和样品卡各占 90×110 mm，中心 X=±75 mm，左右对称。后沿放灰/白参考条，前沿留参考尺度条。两张卡的有效表面应同高、平整、朝向一致；夹具压边不要遮住采样 ROI。可交换两张卡左右位置，检验照明梯度对结果的影响。

底板使用哑光中性表面，黑色外帘用于遮光。两侧漫射灯从向下垂线内倾 35° 起调，并不保证实际照度均匀。先排除反光、阴影和饱和，再记录灯电流/调光档位、预热时间、相机曝光、模拟/数字增益、AWB/色彩矩阵/Gamma 状态。两侧分别调光，但成对记录参数。

初期屏幕可显示同一帧两 ROI 的 R/G/B 均值、通道差和明确命名的 RGB 距离。**未经色度标定的 RGB 距离不能标成标准 ΔE。** 实现标准色差还需要规定光照、相机颜色校准、颜色空间/白点及相应计算。机械框架只提供重复布置条件。

反光样品先加大漫射面积/改变入射方向；后续可增加光源偏振片和镜头检偏片，但须重新验证颜色与曝光。漫射/偏振适合抑制镜面反光，背光适合轮廓成像，这些照明思路参见 [Edmund Optics 照明说明](https://www.edmundoptics.com/knowledge-center/application-notes/illumination/choose-the-correct-illumination/)；此处没有指定采购型号。

### 尺寸测量载板（scene="measure"）

模型划出 210×120 mm 主测量区域，放置长方形和带圆孔圆片作为示意。左侧放纵向尺度，前沿放横向尺度；用三个边缘定位挡块复位载板，工件另加可换 L 形挡块/轻压夹。挡块不能挡住待识别轮廓。

优先测量平面轮廓。标定板、已知尺寸的参考件或卡尺锁定后的已知间距，必须与被测轮廓处于同一 Z 平面。卡尺可用于复核参考件尺寸，但不能仅凭图像中“有一把卡尺”就自动获得可靠尺度。圆孔应区分上沿、下沿及倒角，不能混测。

推荐次序：检查平面和相机垂直度 → 标定镜头畸变 → 在测量平面进行像素到毫米映射 → 用独立已知尺寸参考件验证 → 记录误差和重复性。若存在透视倾斜，使用平面映射/校正，不能整幅图只套一个比例。官方 [OpenCV 相机标定说明](https://docs.opencv.org/4.x/d4/d94/tutorial_camera_calibration.html)解释了畸变和内参；可用离线标定得到参数，演示核心处理仍需依项目方案在 FPGA 端落实。

理想垂直、低畸变、同平面的近似：`kx=Lref_x/Nref_x`、`ky=Lref_y/Nref_y`，单位 mm/px；任意方向线段应在校正后的物理坐标中求长度。圆/圆弧拟合也应在物理坐标或正确校正图像中完成；局部遮挡或短圆弧会降低拟合可靠性。

假设 320×180 mm 恰好覆盖完整 1280×720 有效图像，则两个方向名义采样为 0.25 mm/px。它是采样间距，**不是 ±0.25 mm 精度承诺**；缩放/裁剪、镜头畸变、边缘定位和工件高度都会改变结果。若参考面到成像中心距离近似 H，工件轮廓高出参考面 t，直接用参考面尺度会产生约 `t/(H-t)` 的尺寸高估；以 H≈400、t=5 为例约 1.27%。模型的 5 mm 示意工件必须使用同高参考面重新标定，或先换成薄片演示。

后续可换成背光台或增加低角度侧光。当前载板下面是实心底座，**背光尚未建模**；加入时要设计开窗、支撑、漫射层和相同高度基准。

### 标定载板（scene="calibration"）

20 mm 方格、14×8 格只是占位图案，实际内角点为 13×7。SCAD 不是精度标定靶的制造文件；打印后必须复测横纵尺寸、平整度和缩放误差。镜头内参标定可能需要多位置/多姿态采样，测量平面映射则在最终锁定位置完成。

## 3. 参数与坐标

完整表见 [PARAMETERS.md](PARAMETERS.md)；必须实测项目见 [MEASUREMENTS.md](MEASUREMENTS.md)。

- 单位：mm、角度为度。原点在暗箱中心固定台面上表面；X 向右、Y 向后、Z 向上。
- 固定台面 Z=0，可换载板上表面 Z=`insert_t`=3；`camera_h` 指镜头前端到该参考面的间距。它不等于厂家从传感器平面定义的工作距离。
- `fov_w/fov_d` 是希望覆盖的范围，模型蓝色锥体只表达空间关系，不预测镜头光学。
- 400 mm 间距覆盖 320×180 mm，在针孔近似下需要全水平/垂直视角约 43.6°/25.4°。镜头型号、sensor 读出和输出裁剪未确认，不能把这个数当成现有 SC500CS 视角。
- 如果实测在 H0 的视场为 W0，固定同一镜头和输出模式时可用 `H≈H0×Wtarget/W0` 初估高度，随后实测修正并重新标定。减小视场可提高采样密度；不要仅为了覆盖范围而牺牲测量分辨率。

## 4. 文件与模块

```text
mechanical/frame_concept/
  frame_concept.scad     # 总装入口、底座/立柱/斜撑/挂点/帘布/走线
  parameters.scad        # 所有可调参数、派生坐标、范围断言
  common.scad            # 梁、长孔、标识、示意线缆
  camera_mount.scad      # 相机托板、顶部横梁、竖向滑柱
  monitor_mount.scad     # 假设 VESA 板、独立立柱与屏幕包络
  board_tray.scad        # 开发板托盘、安装臂、接头操作包络
  light_mount.scad       # 条形灯、两端转轴、独立 L 形支架概念
  fixtures.scad          # 颜色/尺寸/标定三类可换载板
  presets.json          # OpenSCAD Customizer 场景预设
  scripts/render.ps1    # OpenSCAD 几何检查与预览生成
  previews/             # 总装、测量、标定、闭帘及俯视预览/日志
  README.md
  PARAMETERS.md
  MEASUREMENTS.md
  TASK_RECORD.md         # 本轮角色、基线、范围、验证边界
```

模块文件供入口 include；请打开 `frame_concept.scad`，不要直接打开子模块期待出现完整总装。铝型材是实心方包络，未画槽、T 螺母、全部角码和紧固件；滑座和显示器连接件是概念件。相机/开发板孔阵列默认为空，实际固定方式尚待实测后细化，不能按绿色包络块直接钻孔。

视图选择：`part="assembly"` 为总装，`part="optics"` 隐去外围框架以观察相机/灯具关系，`part="worktop"` 只显示载板。尺寸与颜色场景的载板俯视图见 `previews/*_layout.png`。

## 5. 打开、修改和导出

使用 OpenSCAD 2021.01 或兼容版本，无第三方库。打开入口，F5 预览；修改 `parameters.scad` 或使用命令行 `-D`。装配空间检查可以开关半透明帘布、目标视场和线缆示意。实际帘布应不透光；预览透明度仅为了看清内部。

```powershell
# 在本目录执行；若未加入 PATH，使用 openscad.com 的完整路径。
openscad.com -o previews/measure_custom.png --imgsize=1600,1100 --viewall --autocenter `
  -D 'scene="measure"' -D 'camera_h=350' -D 'show_fov=false' frame_concept.scad

# 选择预设
openscad.com -p presets.json -P enclosed -o previews/enclosed_custom.png `
  --imgsize=1600,1100 --viewall --autocenter frame_concept.scad

# 导出单件概念 STL；未补实测尺寸前不要直接制造。
openscad.com -D 'part="camera_plate"' -o camera_plate_concept.stl frame_concept.scad

# 重建全部检查与预览；脚本使用 ProcessStartInfo 保留 Windows 引号。
./scripts/render.ps1 -OpenSCAD 'C:/Program Files/OpenSCAD/openscad.com'
```

`parameters.scad` 保留 OpenSCAD Customizer 分组；如软件未将 include 中参数显示为控件，可直接编辑参数文件或用 `-D`。`presets.json` 只切换场景，主尺寸仍集中在参数文件。命令行用法参考 [OpenSCAD 官方手册](https://files.openscad.org/documentation/manual/Using_OpenSCAD_in_a_command_line_environment.html)。

改尺寸顺序：实测镜头视场/线缆 → 相机高度及暗箱净空 → 载板/ROI → 灯位及挡光 → 板卡托盘 → 显示器和底座。修改后运行检查脚本并人工看图；断言只捕获部分包络关系，不是全自动碰撞或承载校核。

## 6. 布线、散热与拆装

MIPI 示意线从相机走向右侧挡光穿线口，再到板卡；**不默认延长 MIPI 排线或增加转接头**。先用实际排线摆位，核实触点方向、连接器位置、动态弯曲禁区及厂家允许长度。默认直达路由也可能超出现有短排线能力，此时优先把托盘移近相机，必要时把板卡放入顶部独立散热侧舱并改变挡光分区，不强行拉长排线。

HDMI、电源、下载线走外侧通道；灯电源单独绑扎，接头附近留应力释放。30 mm 走线槽和 35 mm 接头余量只是空间起点，弯曲半径/插拔距离按真实线缆调整。示意线不表示电气端口方位或引脚定义。灯具调光器和供电放在箱外，板卡风道避开帘布，进出风口可用折线路径遮光；不把排线当作相机受力支撑。

搭建顺序：校平台面并固定框架/斜撑 → 装相机并确认原始图像 → 用实物确定视场/高度并锁紧 → 摆放开发板并验证 MIPI → 装灯和帘布 → 固定显示器 → 装载板并标定。显示器质量、重心、底座紧固/防倾覆和相机挠度须实测校核；若屏幕更大或更重，优先使用有额定承载的独立成品桌夹支架，勿沿用本假设支架。

## 7. AE/AWB 扩展与验证

保留双路灯电流/调光档位记录，设可复位的灰/白参考位置；后续在顶梁追加第三路可换色温光源、侧光和传感器夹具。新增光源要先确认频闪、光谱、散热和驱动兼容性，不在此模型中假设 FPGA 已具备控制端口。

| 实验 | 固定因素 | 唯一主要变量与记录 |
|---|---|---|
| 颜色对比 | 曝光/增益/AWB/色彩处理、灯位和照明状态 | 换样品；记录同帧 ROI 均值及交换位置的变化 |
| 几何测量 | 相机/镜头、输出模式、参考平面、照明 | 换已知尺寸工件；记录中心和边缘位置的误差、重复放置离散度 |
| AE 验证 | 光谱/灯位、白平衡、样品与 ROI | 阶跃改变照度，记录亮度、曝光/增益、过曝占比和稳定时间 |
| AWB 验证 | 曝光/增益、几何、灰参考 | 改变照明光谱，记录 R/G、B/G 和稳定时间；普通同一白光灯调暗不能代替色温变化 |

灯电流可能同时改变光谱，PWM 可能造成滚动快门条纹，应先以图像验证驱动方案。AE/AWB 实验做完后恢复并核对颜色/尺寸测量的锁定配置和标定编号。机械修改后的整机视频稳定性及原有 OSD 可见性仍需按项目流程在实板重新验证。

## 8. 下一轮迭代

先完成 [MEASUREMENTS.md](MEASUREMENTS.md) 中 P0 项，再决定型材下料和相机/板卡孔位。第二轮加入真实角码、滑座、限位及线缆弯曲包络；第三轮测量照度均匀性、机械重复定位、中心/边缘尺寸误差和闭帘漏光；有证据后再设计背光、偏振和 AE/AWB 控制扩展。

本版只经过软件几何/预览验证，未加工、未承载测试、未光学标定、未生成 bit、未上板。软件验证记录见 [TASK_RECORD.md](TASK_RECORD.md)。
