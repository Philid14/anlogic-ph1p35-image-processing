# 人工实测/确认清单

状态：全部待确认。日期、测量工具、照片/数据路径应与尺寸一起填写。优先完成 P0，才能决定框架大小和加工孔位。不要将默认值抄入“实测”栏。

## P0：确定能否按默认布局搭建

| 对象 | 需要实测/确认 | 实测值/证据 | 影响参数或决策 |
|---|---|---|---|
| 桌面 | 可用宽/深/承重、前方操作空间、搬运限制 | 待填 | `base_w/base_d`，是否保留右侧一体设备区 |
| 板卡 | 确切板型/版本；板外形长宽、上下最高元件、孔坐标/孔径、质量 | 待填 | `board_size/board_holes/board_tray`；不按系列名猜板尺寸 |
| 摄像头 | 模组尺寸、镜头外径/凸出、光轴相对板边位置、安装孔及元件禁区 | 待填 | `camera_body/lens_d/lens_len/camera_holes` |
| 相机镜头/画面 | 镜头型号、对焦范围；在候选高度处的实际视场 W/H、使用的输出格式/裁剪/缩放 | 待填 | `camera_h/fov_w/fov_d`，空间采样与目标可测尺寸 |
| MIPI | 现有线长/可用余量、两端触点朝向、连接器位置、插拔方向、允许弯曲和厂家长度约束 | 待填 | 板卡托盘是否必须移近/升高；不默认可延长 |
| 显示器 | 机身 W/H/T、质量和重心、HDMI/电源口方位、是否有 VESA、孔距/螺纹/允许旋入深度 | 待填 | `monitor_size/monitor_mass_kg/vesa`；无 VESA 则换托架或保留原底座 |
| 样品与色卡 | 最大包络、厚度、夹持边；两卡表面能否同高 | 待填 | 卡区大小、载板范围、参考面高度 |
| 测量需求 | 最大工件 L/W/直径、最小特征、孔/弧被测边界、允许误差、重复性目标、工件高度范围 | 待填 | 反推 FOV/高度/镜头和校准策略，不能先承诺精度 |
| 灯具 | 外形/安装孔、发光面积、散热空间、供电和调光方式、频闪、色温/光谱和显色资料 | 待填 | `light_*`、灯架、扩散板、遮光距离 |

## P1：细化安装与标定

| 项目 | 确认方法与记录 | 状态 |
|---|---|---|
| 型材与连接 | 核对实际型材槽型、角码、滑块、T 螺母、螺纹、梁端连接及工具插入空间 | 待填 |
| 工作台 | 测平整度/载板厚度和弯曲；检查相机光轴相对台面法线；必要时调平 | 待填 |
| 屏幕支架 | 按实际质量/重心检查底座、紧固件、防倾覆与拖线后的稳定性；本模型未承载计算 | 待填 |
| 相机支架 | 锁紧前后位置漂移、轻触框架后的图像位移/恢复时间、长时间高度漂移 | 待填 |
| 标定参考 | 已知尺寸、标定图样实测横纵节距、平整度、参考边/轮廓高度、独立验证件 | 待填 |
| 接头与散热 | 带线测最大包络/弯曲半径/插拔长度；按板卡规范测温并检查布帘间隙 | 待填 |
| 光场 | 用同一灰片遍历 ROI 记录图像亮度/RGB；交换两卡位置；检查反光、饱和和暗角 | 待填 |
| 漏光 | 固定相机参数、固定内部光源，改变室内光和显示器亮度，记录 ROI 是否变化 | 待填 |
| 载板定位 | 反复取放同一参考件，记录中心和边缘尺寸/位置变化 | 待填 |

## P2：建立可重复的实验记录

每次至少记录：载板编号、标定编号、镜头/对焦设置、相机高度、分辨率/裁剪、灯位/倾角、光源驱动参数、预热时间、曝光/增益/AWB/色彩处理状态、样品表面高度、FPGA 版本、原始帧与 OSD 结果。

尺寸测量：已知参考尺寸、测得值、误差、中心/四角位置、重复装夹次数及离散度。颜色比较：两 ROI 统计口径、同帧有效性、换位结果、重复测量和高光剔除方式。AE/AWB：阶跃条件、输入改变时刻、每帧参数和稳定时间；判稳阈值由需求确认后填写，不预先编造验收值。
